keta

Structural analysis: bars, cables, shells and continuum elements

keta is a finite-element kernel for bar structures and bridges, written in C++20 and driven from Python: a script describes the structure, runs the analyses and processes the results.

Before you start

keta is a calculation tool whose verification and validation are still in progress. A large part of its results is compared, by tests, with analytical solutions and with published reference calculations, but this work continues and does not yet cover every use case. keta certainly contains errors that have not yet been found.

The results of a calculation remain the responsibility of the person who carries it out. Before using them in a design, they should be checked against an order of magnitude, a simplified calculation or another program, and the user should make sure that the assumptions of the model suit the structure studied. The tool is provided as is, without warranty of any kind.

If you find a doubtful result, an unclear message or a discrepancy with a reference, please report it, or propose a correction, in the issue tracker of the repository (github.com/Pavlishenku/keta). Attaching a reduced example that reproduces the problem makes it much easier to correct.
