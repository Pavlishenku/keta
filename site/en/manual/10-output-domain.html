Chapter 10 Output domain

10.1 Output sections#

The internal forces of a bar are output at output sections evenly distributed along its length, ends included. Their number per bar is set when the analysis is launched by the parameter stations (or stations_per_bar):

Syntax
m.analyze(stations=11, stations_abs=None)  →  Results
ParameterUnitDefaultMeaning
stations—11number of output sections per bar, ends included (11: every tenth of the length); at least 2 to obtain the ends (1: mid-length section only)

The same parameter exists for the other static analyses (second_order, cable_static, analyze_link_laws, phased) and for the harmonic response. The forces at the output sections are exact for span loads (concentrated, distributed, linearly varying): they are obtained by integration of the equilibrium of the bar from its end forces, and not by interpolation.

Syntax
case_.bar_forces(bar)  →  [(x/L, N, Vy, Vz, T, My, Mz), …]
case_.end_forces(bar)  →  [12 values]

bar_forces returns a list ordered from the origin to the end; each item gives the relative abscissa x/L then the six forces defined in Section 3.5. To obtain the force at a precise abscissa, the number of output sections is chosen so that it is one of them, or the bar is split at that point.

Note

The number of output sections has no influence on the accuracy of the nodal displacements nor on that of the forces: it only sets the points where the forces are output. The maximum moment of a bar under a point load is output only if the load is placed on an output section.

10.2 Stresses#

The normal stress at a point (y, z) of a section is obtained from the forces by the relation σ = N/A + My·z/Iy − Mz·y/Iz (Section 3.5). The properties A, Iy and Iz are those of the section (given or read in the JSON model).

10.3 Generalised stresses#

The study of a stress at a particular point (shear stress with the effect of the depth variation, stress in a tendon, force in a fibre) often reduces to a linear combination of the forces of the section, possibly completed by a constant:

C = cN·N + cVy·Vy + cVz·Vz + cT·T + cMy·My + cMz·Mz + c0

In Python, such a quantity is computed directly from bar_forces, with coefficients that are constant or variable along the abscissa (linear, parabolic, arbitrary). It can then be combined and enveloped like any other result (Chapter 19).

Exampleexamples/manual/ex_stations.py
# Result stations: subdivision of the bars, reading of the forces, stresses and
# "generalised stress" (linear combination of forces) computed in Python.
import keta

def z(x):                                         # removes the displayed negative zero
    return 0.0 if abs(x) < 1e-6 else x

L, q = 12.0, -40e3
m = keta.Model()
a, b = m.add_node(0, 0, 0), m.add_node(L, 0, 0)
beam = m.add_beam(a, b, m.add_section_rect(0.4, 1.0), m.concrete())
m.add_support(a, dx=True, dy=True, dz=True, rx=True)
m.add_support(b, dy=True, dz=True)
m.add_udl(beam, wz=q)
m.add_point_load(b, fx=-500e3)                    # compression of 500 kN

case_ = m.analyze(stations=7).case(1)             # 7 result stations per bar (step L/6)
A, I, v = 0.4 * 1.0, 0.4 * 1.0**3 / 12, 0.5
print("  x/L      x [m]      N [kN]    Vz [kN]    My [kN.m]  sig_bot [MPa]  sig_top [MPa]")
for x, N, Vy, Vz, T, My, Mz in case_.bar_forces(beam):
    s_bot = N / A + My * (-v) / I                 # sigma = N/A + My z / Iy
    s_top = N / A + My * (+v) / I
    print(f"{x:6.4f} {x * L:9.3f} {N / 1e3:11.2f} {z(Vz) / 1e3:10.2f} {z(My) / 1e3:12.2f} "
          f"{s_bot / 1e6:14.3f} {s_top / 1e6:14.3f}")
# generalised stress: C = 0.25 N + 0.33 My + 10 (any combination of forces)
C = [0.25 * s[1] + 0.33 * s[5] + 10.0 for s in case_.bar_forces(beam)]
print("generalised stress C(x):", " ".join(f"{c / 1e3:.2f}" for c in C), "(x 1000)")
print("end forces (local axes, 12 components):")
print(" ", " ".join(f"{f / 1e3:.1f}" for f in case_.end_forces(beam)))
Output

0.1667     2.000     -500.00    -160.00      -400.00          4.750         -7.250

The end forces (last line) are the actions of the nodes on the bar: axial force +500 kN at the origin (opposite to N = −500 kN) and −500 kN at the end (equal to N), vertical reactions of 240 kN at both ends.

10.4 Imposed output sections and other results#

Syntax
m.analyze(stations=11, stations_abs={bar: [x, …]})  →  Results
case_.bar_deflections(bar)  →  [(x/L, u, v, w, θx, θy, θz), …]
case_.stresses(bar)  →  [(x/L, point, σ, τ, σ_VM), …]
case_.soil_pressure(bar)  →  [(x/L, px, py, pz, mx), …]
case_.shell_forces(shell)  →  dict(n, m, q, n_principal, m_principal)
ParameterUnitDefaultMeaning
stations_absmNoneabscissae of the output sections, measured from the origin of each bar cited; the other bars keep stations evenly spaced sections

bar_deflections gives the displacements and rotations at the output sections in the local axes of the bar (θy​=−dw/dx). Being obtained by double integration of the curvature from the displacements of the ends, they are exact between the nodes for the usual loads. stresses evaluates σ=N/A+My​z/Iy​−Mz​y/Iz​ at the stress points of the section (four corners and centre of a rectangle, extreme fibres of a steel section), with an estimate of τ and the von Mises stress. soil_pressure gives the reaction p=kw of an elastic foundation. shell_forces returns the forces of a shell at its centre: membrane forces n = (nx, ny, nxy) in N/m, moments m = (mx, my, mxy) in N·m/m, shear forces q = (qx, qy), and the principal values with their angle.

Exampleexamples/manual/ex_etude_resultats.py
# Imposed result stations, displacements, stresses and soil pressure at the result stations.
import keta

L, q = 10.0, 20e3
m = keta.Model()
a, b = m.add_node(0, 0, 0), m.add_node(L, 0, 0)
p = m.add_beam(a, b, m.add_section_rect(b=0.4, h=0.6), m.add_material(e=30e9, nu=0.2))
m.add_support(a, dx=True, dy=True, dz=True, rx=True, rz=True)
m.add_support(b, dy=True, dz=True, rz=True)
m.add_udl(p, wz=-q)
r = m.analyze(stations_abs={p: [0.0, 2.5, 5.0, 7.5, 10.0]})
case_ = r.case(1)
for (xl, N, Vy, Vz, T, My, Mz), (_, u, v, w, tx, ty, tz) in zip(case_.bar_forces(p), case_.bar_deflections(p)):
    print(f"x = {xl * L:4.1f} m: My = {My / 1e3:7.2f} kN.m (q x (L-x)/2 = {q * xl * L * (L - xl * L) / 2e3:7.2f}),"
          f" w = {w * 1e3:7.3f} mm")
for xl, point, sigma, tau, vm in case_.stresses(p):
    if abs(xl - 0.5) < 1e-9:
        print(f"midspan, point {point:>6}: sigma = {sigma / 1e6:7.3f} MPa")

# beam resting on an elastic soil, without vertical support: w = q/k and p = q
m = keta.Model()
nd = [m.add_node(2.0 * i, 0, 0) for i in range(7)]
s = m.add_section_rect(b=1.0, h=0.5)
br = [m.add_beam(nd[i], nd[i + 1], s, m.concrete()) for i in range(6)]
m.add_support(nd[0], dx=True, dy=True, rx=True, rz=True)
for x in br:
    m.set_soil(x, kfz=5e7)
    m.add_udl(x, wz=-40e3)
c = m.analyze().case(1)
print(f"settlement = {c.displacement(nd[3])[2] * 1e3:.4f} mm (q/k = {40e3 / 5e7 * 1e3:.4f})")
print("soil pressure under bar 3 [kN/m]:", [round(abs(row[3]) / 1e3, 2) for row in c.soil_pressure(br[2])])

The rectangular section has shear areas: the elastic foundation of these bars is therefore represented by a cubic consistent matrix (Section 6.10). At the nodes, the settlement takes its theoretical value q/k; inside the bars, the soil pressure exceeds the theoretical value q by at most 1.1 % with bars of 2 m, a deviation that decreases roughly as the square of the length of the bars. Without shear areas or releases, the linear statics computes the same beam by the exact solution of the beam on elastic foundation, and the pressure equals q at every section.
