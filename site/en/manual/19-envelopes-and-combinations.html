Chapter 19 Envelopes and combinations

19.1 Linear combinations#

Syntax
m.add_combination(terms, name=None)  →  int
ParameterUnitDefaultMeaning
terms——list of pairs (coefficient, case number)
name—Nonename of the combination

A combination is the weighted sum of the results of several load cases. It is computed by m.analyze() at the same time as the cases, and its results are read by r.combo(number) with the same methods as a case; r.combo_ids gives the list of the combinations. Combinations have their own numbering (1, 2, …), independent of that of the cases.

Note

Combining results assumes linearity. For nonlinear computations (unilateral supports, link laws, second order, large displacements), create a load case that contains the factored loads of the combination and compute it directly.

19.2 Envelopes#

An envelope is the set of extreme values of a quantity over several cases, combinations or load arrangements. Since the results are Python numbers, an envelope is built directly by min and max over the lists of values, with the desired presence logic (permanent load always present with its favourable or unfavourable factor, variable loads present or absent). The concomitant values are obtained by keeping, with the extreme, the index of the combination that produces it.

For moving loads, the extremes are given directly by the placement functions of Chapter 12, which also return the corresponding position.

19.3 EN 1990 code combinations#

Syntax
keta.combine_extreme(effects, actions, state='uls', maximise=True, rules={})  →  dict
ParameterUnitDefaultMeaning
effects——effect of each action for a unit factor (one value per action)
actions——description of the actions: dict(case, name, kind, gamma_sup, gamma_inf, psi0, psi1, psi2, exclusive, may_lead)
state—'uls'limit state: 'uls' (fundamental ULS), 'characteristic', 'frequent', 'quasi_permanent'
maximise—Truesearch for the maximum (False: minimum)
rules—{}National Annex rules: dict(gamma_G_sup, gamma_G_inf, gamma_set_sup, gamma_set_inf, xi, eq610ab)

Each action is permanent (kind='permanent'), settlement ('settlement') or variable ('variable', default). For a variable action, gamma_sup is 1.5 and gamma_inf 0 by default; ψ0, ψ1, ψ2 are 0.7, 0.5 and 0.3. Actions carrying the same label exclusive cannot act together; may_lead=False prevents an action from being leading. The function searches for the most unfavourable combination among all those these rules allow: each permanent action with its favourable or unfavourable factor, each variable action leading or accompanying, present or absent. It returns dict(value, label, terms), terms being the list of the pairs (case, coefficient) of the combination found. With eq610ab=True, the ULS uses Expressions 6.10a and 6.10b instead of 6.10.

Exampleexamples/manual/ex_combinaisons.py
# Combinations and envelopes: continuous beam 2 x 10 m, permanent loads and
# live loads span by span; combinations, envelope and EN 1990 extreme.
import keta

m = keta.Model()
nd = [m.add_node(1.0 * i, 0, 0) for i in range(21)]
sec = m.add_section_props(sx=0.4, iy=0.02, iz=0.01, ix=0.01)
b = [m.add_beam(nd[i], nd[i + 1], sec, m.concrete() if i == 0 else 1) for i in range(20)]
m.add_support(nd[0], dx=True, dy=True, dz=True, rx=True)
m.add_support(nd[10], dy=True, dz=True)
m.add_support(nd[20], dy=True, dz=True)
for bi in b:
    m.add_udl(bi, wz=-20e3, case=1)                       # G: 20 kN/m
for bi in b[:10]:
    m.add_udl(bi, wz=-15e3, case=2)                       # Q1: span 1
for bi in b[10:]:
    m.add_udl(bi, wz=-15e3, case=3)                       # Q2: span 2
for c, name in [(1, "G"), (2, "Q span 1"), (3, "Q span 2")]:
    m.name_case(c, name)
c1 = m.add_combination([(1.35, 1), (1.5, 2), (1.5, 3)], name="ULS two spans")
c2 = m.add_combination([(1.35, 1), (1.5, 2)], name="ULS span 1")
r = m.analyze(stations=11)
print(r)
for c in r.combo_ids:
    res = r.combo(c)
    print(f"{res}: M over support = {res.bar_forces(b[9])[-1][5] / 1e3:8.2f} kN.m, "
          f"M at x = 4 m = {res.bar_forces(b[3])[-1][5] / 1e3:8.2f} kN.m")

# Programmed envelope: G always present (1.35 or 1.0), each Q present (1.5) or absent
def forces(case_id, bar):
    return [s[5] for s in r.case(case_id).bar_forces(bar)]
env = {}
for bi in b:
    G, Q1, Q2 = forces(1, bi), forces(2, bi), forces(3, bi)
    vals = [[gG * g + a * q1 + c * q2 for g, q1, q2 in zip(G, Q1, Q2)]
            for gG in (1.0, 1.35) for a in (0.0, 1.5) for c in (0.0, 1.5)]
    env[bi] = [(min(v), max(v)) for v in zip(*vals)]
mmin = min(lo for bi in b for lo, _ in env[bi])
mmax = max(hi for bi in b for _, hi in env[bi])
print(f"envelope of My: min {mmin / 1e3:.2f} kN.m (spans), max {mmax / 1e3:.2f} kN.m (support)")

# Exact extreme of a response according to EN 1990 (effects of the unit actions given)
e = [r.case(c).bar_forces(b[9])[-1][5] for c in (1, 2, 3)]
x = keta.combine_extreme(e, [dict(case=1, kind="permanent"),
                             dict(case=2, name="Q1", psi0=0.7),
                             dict(case=3, name="Q2", psi0=0.7)], state="uls", maximise=True)
print(f"EN 1990, ULS, max of the moment over support: {x['value'] / 1e3:.2f} kN.m; {x['label']}; terms {[(c, round(f, 4)) for c, f in x['terms']]}")
x = keta.combine_extreme(e, [dict(case=1, kind="permanent"), dict(case=2, name="Q1"), dict(case=3, name="Q2")],
                         state="characteristic", maximise=True)
print(f"EN 1990, characteristic SLS: {x['value'] / 1e3:.2f} kN.m; terms {[(c, round(f, 4)) for c, f in x['terms']]}")
Output

<keta.CaseResult 'ULS span 1': 21 nodes, 20 bars>: M over support =   478.13 kN.m, M at x = 4 m =  -402.75 kN.m
envelope of My: min -402.75 kN.m (spans), max 618.75 kN.m (support)
EN 1990, ULS, max of the moment over support: 576.56 kN.m; ULS 6.10, leading: Q1; terms [(1, 1.35), (2, 1.5), (3, 1.05)]

The programmed envelope reproduces the two explicit combinations. The EN 1990 combination with ψ0 = 0.7 gives for the moment over the support a value lower than the combination “all loads at 1.5”: the second span enters it only as an accompanying action (1.5 × 0.7 = 1.05).

19.4 Generation of combinations and envelopes#

Syntax
m.generate_combinations(permanent, variable=[], state='uls', use_610ab=False, xi=0.85)  →  [ids]
r.envelope(cases=None, combos=None)  →  (minimum, maximum)
r.envelope_factored([(case, c_min, c_max), …])  →  (minimum, maximum)
r.concomitant(what, bar=0, station=0, comp=0, node=0, cases=None, combos=None)  →  dict
ParameterUnitDefaultMeaning
permanent——permanent cases, or dict(case, gamma_sup=1.35, gamma_inf=1.0) — the same pair for all
variable—[]dict(case, name, psi0, psi1, psi2, gamma_q), or (case, 'traffic'|'wind'|'thermal'|'snow') for the values of the French National Annex
state—'uls''uls', 'characteristic', 'frequent', 'quasi_permanent'
what——'bar_force' (bar, output station number, component 0 to 5: N Vy Vz T My Mz), 'reaction' or 'displacement' (node, component)

generate_combinations adds to the model the combinations of the requested state, each variable action being leading in turn, and returns their numbers. At ULS (6.10):

j∑​γG,j​Gj​+γQ,1​Q1​+i>1∑​γQ,i​ψ0,i​Qi​(19.1)

the permanent actions being all taken at γG,sup​, then all at γG,inf​. The envelopes cover all the components: the two bounds returned are used like an ordinary result (bar_forces, reactions…). envelope_factored takes each case alone, with the coefficient of its interval that is the most unfavourable to it: this is not a combination. concomitant searches for the extremes of a component and returns, with them, the complete state of the case or combination that produces them, for example a moment with its concomitant axial force.

Exampleexamples/manual/ex_combinaisons_en1990.py
# EN 1990 combinations generated in the model, envelopes and concomitant values.
import keta

L = 10.0
m = keta.Model()
a, b = m.add_node(0, 0, 0), m.add_node(L, 0, 0)
p = m.add_beam(a, b, m.add_section("HEB300"), m.steel())
m.add_support(a, dx=True, dy=True, dz=True, rx=True, rz=True)
m.add_support(b, dy=True, dz=True, rz=True)
m.add_udl(p, wz=-10e3, case=1); m.name_case(1, "G")
m.add_udl(p, wz=-5e3, case=2); m.name_case(2, "traffic")
m.add_udl(p, wz=2e3, case=3); m.name_case(3, "wind")
uls = m.generate_combinations([1], [(2, "traffic"), (3, "wind")], state="uls")
qp = m.generate_combinations([1], [(2, "traffic"), (3, "wind")], state="quasi_permanent")
r = m.analyze()
for i in uls + qp:
    print(f"combination {i}: reaction at A = {dict(r.combo(i).reactions())[a][2] / 1e3:8.2f} kN")
low, high = r.envelope(combos=uls)
print(f"ULS envelope of My at midspan: [{low.bar_forces(p)[5][5] / 1e3:.2f}; {high.bar_forces(p)[5][5] / 1e3:.2f}] kN.m")
cc = r.concomitant("reaction", node=a, comp=2, combos=uls)
print(f"maximum reaction {cc['max'] / 1e3:.2f} kN ({cc['source_max']}), "
      f"concomitant My = {cc['state_max'].bar_forces(p)[5][5] / 1e3:.2f} kN.m")
