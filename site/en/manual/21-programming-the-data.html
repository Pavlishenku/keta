Chapter 21 Programming the data

21.1 Overview#

The data of a keta computation are a Python program: variables, mathematical expressions, loops, conditions, functions and data structures are those of the language. This chapter recalls the constructs most useful for describing a model and processing its results. They require no particular keta command.

21.2 Variables and expressions#

import math
L, n = 30.0, 12                      # span and subdivision
h = max(L / 20, 1.0)                 # depth
alpha = math.radians(30)             # angles in radians
I = 0.4 * h**3 / 12

The math module provides the usual functions (sqrt, sin, cos, exp, log, pi, …).

21.3 Lists and dictionaries of identifiers#

The identifiers returned by the add_… methods are stored in lists or dictionaries, which serve as named lists of objects:

nodes = [m.add_node(L * i / n, 0, 0) for i in range(n + 1)]
bars = [m.add_beam(nodes[i], nodes[i + 1], sec, mat) for i in range(n)]
piers = {"P1": nodes[4], "P2": nodes[8]}
central_span = bars[4:8]

21.4 Loops and conditions#

for i, nd in enumerate(nodes):
    if i in (0, n):
        m.add_support(nd, dz=True)
    elif i % 4 == 0:
        m.add_support(nd, kz=50e6)

The break and continue statements interrupt a loop or move on to the next iteration.

21.5 Functions#

A function that builds a model from parameters serves to compare variants, to carry out parametric studies or to simulate construction stages by successive models. The following example simulates the incremental launching of a deck: for each position of advance, a model is built on the supports present, computed and post-processed; the results are written to a CSV table and the envelope of the moments is formed.

Exampleexamples/manual/ex_programmation.py
# Programming the data: launching of a 90 m deck by incremental launching, on a casting bed
# (supports at x = -90, -60, -30 and 0 m) then on piers at x = 30, 60 and 90 m. For each launching
# position, a model is built, analysed and post-processed; the envelope is formed.
import csv
import io
import keta

L, mesh_step, q = 90.0, 2.5, -150e3
fixed_supports = [-90.0, -60.0, -30.0, 0.0, 30.0, 60.0, 90.0]

def deck(advance):
    """Model of the deck whose front end is at x = advance."""
    m = keta.Model()
    concrete = m.add_material(e=36e9, nu=0.2, rho=0.0)
    sec = m.add_section_props(sx=6.0, iy=5.0, iz=40.0, ix=8.0)
    xs = [advance - L + mesh_step * i for i in range(int(L / mesh_step) + 1)]
    nd = {round(x, 6): m.add_node(x, 0, 0) for x in xs}
    keys = sorted(nd)
    bars = [m.add_beam(nd[keys[i]], nd[keys[i + 1]], sec, concrete) for i in range(len(keys) - 1)]
    under = [x for x in fixed_supports if keys[0] <= x <= keys[-1]]
    for k, x in enumerate(under):
        m.add_support(nd[x], dx=(k == 0), dy=True, dz=True, rx=True)
    for b in bars:
        m.add_udl(b, wz=q)
    return m, bars, under

table = io.StringIO()                       # CSV table (here in memory; open("launching.csv", "w") otherwise)
writer = csv.writer(table, delimiter=";")
writer.writerow(["advance [m]", "supports", "M min [kN.m]", "M max [kN.m]"])
env_min, env_max = (0.0, None), (0.0, None)
for advance in [5.0 * i for i in range(19)]:
    m, bars, under = deck(advance)
    case_ = m.analyze(stations=3).case(1)
    M = [s[5] for b in bars for s in case_.bar_forces(b)]
    writer.writerow([advance, len(under), round(min(M) / 1e3, 1) + 0.0, round(max(M) / 1e3, 1) + 0.0])
    if min(M) < env_min[0]:
        env_min = (min(M), advance)
    if max(M) > env_max[0]:
        env_max = (max(M), advance)
print(table.getvalue().strip())
print(f"envelope: span moment {env_min[0] / 1e3:.1f} kN.m (advance {env_min[1]} m), "
      f"moment over support {env_max[0] / 1e3:.1f} kN.m (advance {env_max[1]} m)")
print(f"check: cantilever of 25 m, q L²/2 = {-q * 25**2 / 2 / 1e3:.1f} kN.m")

21.6 Retrieving results into variables#

Any result value is a Python number that can be assigned to a variable, compared or used in a later computation:

QuantityExpression
vertical displacement of a noder.case(1).displacement(n)[2]
vertical reaction of a supportdict(r.case(1).reactions())[n][2]
moment My of a bar at its output station kr.case(1).bar_forces(b)[k][5]
maximum moment of a list of barsmax(s[5] for b in bars for s in case_.bar_forces(b))
extreme value of a vehicleketa.convoy_extreme(line, vehicle)[0]
effective force of a tendon at the end of a stager.phase(i).tendons()[0][3]

first natural frequencym.modal().frequencies[0]

21.7 Error handling#

A computation that fails raises an exception (Section 1.5). In a loop, the statement try … except ValueError records the failure and lets the loop continue, as in the example of the fire analysis (Chapter 18) where the absence of equilibrium signals failure.

Finally, the statement assert condition stops the script if a condition is not met: it serves to check a result against a known value (closed forms of the examples of this manual) and to turn a computation script into a non-regression test.
