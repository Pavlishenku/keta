Chapter 5 General commands

5.1 Importing the module#

Syntax
import keta
keta.__version__  →  str

All classes and functions are accessible in the keta namespace. The attribute __version__ gives the version of the module. If the compiled extension cannot be found, the import fails with a message reminding the user to build the _keta target and to complete PYTHONPATH (Chapter 2).

5.2 Creating a model#

Syntax
m = keta.Model()  →  Model

Creates an empty model. A script can create as many models as necessary; they are independent. The following attributes give information on the size of the model:

Syntax
m.node_count  →  int
m.bar_count  →  int
repr(m)  →  str

node_count and bar_count give the number of nodes and of bars (beams and trusses, cables excluded). The representation repr(m), also obtained by print(m), summarises the model: number of nodes, bars, cases and combinations.

5.3 Checking a model#

Syntax
m.validate()  →  list[str]

Checks the consistency of the model without analysing it: references to non-existent nodes, materials or sections, bars of zero length, non-finite values, thermal action on a material without a coefficient of thermal expansion, etc. Returns the list of problems found, empty if the model is sound. The check stops at the first problem encountered: the list contains at most one message.

Note

Each analysis performs this check itself and raises a ValueError if there is a problem; validate() allows it to be done separately, for example before a loop of analyses. An unstable structure (mechanism) is detected only during the analysis, at the factorisation.

5.4 Saving and reloading a model#

A model can be saved as text in JSON format, then rebuilt identically:

Syntax
m.to_json()  →  str
keta.Model.from_json(text)  →  Model
ParameterUnitDefaultMeaning
text——JSON string produced by to_json

The JSON text contains the nodes, materials, sections (with their computed properties), bars, cables, supports, skew supports, rigid and elastic links (with their laws), linear relations, slabs, shells, continuum elements, point, nodal and bar masses, tendons, load cases and combinations. It is written to a file by the usual Python means (open(...).write(m.to_json())). The reloaded model keeps the numbering: identifiers created afterwards follow the largest existing identifiers.

The JSON content is also the means of knowing the properties actually used by the kernel (shear areas of the sections, for example, Chapter 6): json.loads(m.to_json())["sections"].

Important

The time-dependent laws of the materials (set_concrete_law and set_concrete_law_functions, Chapter 7) are not part of this save: they must be defined again after reloading. Tapered bars (set_tapered) and composite bars cannot be saved: to_json refuses a model that contains them rather than write it without them.

5.5 Exporting as a script#

Syntax
m.export_script(results=None, stations=11)  →  str
ParameterUnitDefaultMeaning
results—NoneResults object of a static analysis: the produced script then checks that it finds the same values
stations—11number of output stations per bar for the check analysis

Returns a stand-alone Python script that rebuilds the model and analyses it again. This script serves to archive an analysis in a readable form, to pass on a model or to build a non-regression test when the argument results is supplied.

Exampleexamples/manual/ex_modele_json.py
# General commands: description, validation, saving and reading back of a model.
import json
import keta

m = keta.Model()
n = [m.add_node(5.0 * i, 0.0, 0.0) for i in range(3)]
s = m.add_section_rect(0.30, 0.60)
c = m.concrete()
b = [m.add_beam(n[i], n[i + 1], s, c) for i in range(2)]
for nd in n:
    m.add_support(nd, dy=True, dz=True, rx=True)
m.add_support(n[0], dx=True)
m.add_udl(b[0], wz=-20e3, case=1)
m.name_case(1, "span 1 loaded")

print(m)                                   # model summary
print("nodes:", m.node_count, " bars:", m.bar_count)
print("problems detected:", m.validate())

text = m.to_json()                         # full model in JSON
d = json.loads(text)
print("JSON sections:", sorted(k for k in d if d[k]))
m2 = keta.Model.from_json(text)            # reading back
r1 = m.analyze().case(1).displacement(n[1])[4]
r2 = m2.analyze().case(1).displacement(n[1])[4]
print(f"rotation over support: {r1:.6e} rad (original), {r2:.6e} rad (read back)")
assert r1 == r2

script = m.export_script()                 # the model as a Python script
print("exported script:", len(script.splitlines()), "lines; start:")
print("\n".join(script.splitlines()[:3]))
print("module version:", keta.__version__)
Output

problems detected: []
JSON sections: ['bars', 'cases', 'materials', 'nodes', 'sections', 'supports']

5.7 Online help#

Each method and each function carries a description (in English) accessible through the Python help function, which gives the signature, the default values and the accepted keywords:

help(keta.Model.add_beam)
help(keta.Model.phased)
print(keta.convoy_extreme.__doc__)
