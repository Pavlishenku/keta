Chapter 6 Description of the geometry

The geometry of the structure is defined by the description of:

  • the nodes;
  • the rigid, elastic or skew supports;
  • the bars (beams and trusses), their orientation, their offsets and their hinges;
  • the sections and materials (Chapter 7) of the bars;
  • where applicable, the elastic foundation of bars on soil, the links between nodes, the point masses, the cables, the shells and the continuum elements.

The methods can be called in any order, provided that the referenced objects exist (a bar refers to two nodes, a section and a material already created).

6.1 Nodes#

Syntax
m.add_node(x, y, z)  →  int
ParameterUnitDefaultMeaning
x, y, zm—coordinates of the node in the global axes

Creates a node and returns its identifier. Two nodes may occupy the same position (links between coincident nodes, zero-length springs): they are not merged.

Series of nodes are generated with Python loops and lists. The identifiers are kept in a list (a row of nodes), a list of lists (a grid) or a dictionary indexed by position:

Exampleexamples/manual/ex_noeuds.py
# Generation of nodes and bars by Python loops.
import math
import keta

m = keta.Model()
# 1) A line of 11 nodes every 2 m along X (numbers 1 to 11)
line_x = [m.add_node(2.0 * i, 0.0, 0.0) for i in range(11)]
# 2) A circular arc of radius 15 m, 9 nodes, in the XZ plane
R, angle = 15.0, math.radians(80)
arc = []
for i in range(9):
    t = -angle / 2 + angle * i / 8
    arc.append(m.add_node(10.0 + R * math.sin(t), 8.0, R * math.cos(t) - R * math.cos(angle / 2)))
# 3) A grid of 4 x 3 nodes (numbered row by row)
grid = [[m.add_node(3.0 * i, 20.0 + 2.5 * j, 0.0) for i in range(4)] for j in range(3)]

steel, sec = m.steel(), m.add_section("HEA200")
bars_x = [m.add_beam(line_x[i], line_x[i + 1], sec, steel) for i in range(10)]
bars_arc = [m.add_beam(arc[i], arc[i + 1], sec, steel) for i in range(8)]
print("first and last node of the line:", line_x[0], line_x[-1])
print("nodes of the arc:", arc)
print("row 2 of the grid:", grid[1])
print("bars of the arc:", bars_arc)
print(m)
Output
first and last node of the line: 1 11
nodes of the arc: [12, 13, 14, 15, 16, 17, 18, 19, 20]
row 2 of the grid: [25, 26, 27, 28]
bars of the arc: [11, 12, 13, 14, 15, 16, 17, 18]
<keta.Model: 32 nodes, 18 bars, 0 cases, 0 combos>
Note

The order of creation of the nodes has no influence on performance: the solver renumbers the unknowns to minimise the fill-in of the factorised matrix.

6.2 Rigid supports#

Syntax
m.fix(node)
m.pin(node)
m.add_support(node, dx=False, dy=False, dz=False, rx=False, ry=False, rz=False,
              kx=None, ky=None, kz=None, krx=None, kry=None, krz=None)
ParameterUnitDefaultMeaning
node——identifier of the supported node
dx, dy, dz—Falserestraint of the translations along X, Y, Z (global axes)
rx, ry, rz—Falserestraint of the rotations about X, Y, Z
kx, ky, kzN/mNonestiffness of a translational spring (Section 6.3)
krx, kry, krzN·m/radNonestiffness of a rotational spring (Section 6.3)

fix creates a fixed support (six degrees of freedom restrained), pin a hinge (three translations restrained, rotations free). add_support restrains the chosen components, expressed in the global axes.

Note

Several supports can be declared on the same node; their restraints are cumulated. This is the usual way of restraining the out-of-plane degrees of freedom of a plane structure: for n in nodes: m.add_support(n, dy=True, rx=True, rz=True).

Important

At least one of the supports must prevent each rigid-body motion of the structure, otherwise the analysis fails (“factorization failed (singular or structurally deficient stiffness)”).

6.3 Elastic supports#

A spring is declared by the parameters kx to krz of add_support. It acts along the corresponding component of the global axes, between the node and a fixed point.

Note

A spring placed on a restrained component has no effect: the rigid restraint prevails. A single declaration can combine restraints and springs on different components (m.add_support(n, dy=True, kz=20e6)).

A spring oriented in an arbitrary direction, or a spring with a nonlinear law, is obtained by an elastic link to a fixed node (Section 6.11 and Chapter 17). The example of Section 4.5 (beam on an elastic central support) illustrates a vertical elastic support.

6.3.1 Elastic supports with a full matrix, unilateral supports and uplift#

Syntax
m.set_support(node, uplift=None, decol=None, stiffness=None, rot=0.0, cap=None)
ParameterUnitDefaultMeaning
node——supported node (the support is created if it does not exist)
uplift—Noneunilateral support: dict(component=sign), for example dict(dz=+1); +1: the reaction must remain positive or zero, −1: negative or zero. The component must be restrained by add_support
decol—None“all or nothing” uplift: (axis, sign), axis 'x', 'y' or 'z' global; when the reaction on this axis changes sign, all the components of the support are released
stiffness—Nonestiffness matrix of the support in its own axes: 6 diagonal terms, or 21 terms of the lower half-matrix row by row (dx, dy, dz, rx, ry, rz) [N/m, N·m/rad]
rotrad0rotation of the support axes about global Z (positive sense)
capN, N·mNoneforce cap of a restrained component (yielding of a bearing): dict(component=Rmax), for example dict(dz=2e6); beyond it, the support carries ±Rmax and the node moves. The component must be restrained by add_support

These options complement a support; they are given by name. The stiffness matrix is added to the springs declared by add_support. For 21 terms, the order is that of the lower half-matrix read by rows: k11; k21 k22; k31 k32 k33; …; k61 … k66.

Important

A unilateral support, a support with uplift or a capped support makes the analysis nonlinear: each load case is solved separately by an active-set method, and the results can no longer be superposed. A combination of cases (add_combination) adds the results of the cases; it does not represent the analysis under the sum of the loads. To study a combination, a load case is created that contains all its factored loads. The unilateral conditions are taken into account by linear statics analyze and by staged construction phased; the second-order, large-displacement and link-law analyses treat the support as bilateral.

Exampleexamples/manual/ex_appuis_unilateraux.py
# Unilateral supports, lift-off and elastic support with a full matrix:
# two-span beam of 5 m spans, only the first span loaded.
import math
import keta

Ls, q, EI = 5.0, 10e3, 210e9 * 1e-4

def make_beam():
    m = keta.Model()
    st = m.add_material(e=210e9, nu=0.3, rho=0.0)
    s = m.add_section_props(sx=0.01, iy=1e-4, iz=1e-4, ix=1e-4)
    n = [m.add_node(Ls * i / 4, 0, 0) for i in range(9)]
    b = [m.add_beam(n[i], n[i + 1], s, st) for i in range(8)]
    m.add_support(n[0], dx=True, dy=True, dz=True, rx=True)
    m.add_support(n[4], dy=True, dz=True)
    m.add_support(n[8], dy=True, dz=True)
    for bi in b[:4]:
        m.add_udl(bi, wz=-q)
    return m, n

for option in (None, "uplift", "decol"):
    m, n = make_beam()
    if option == "uplift":
        m.set_support(n[8], uplift=dict(dz=+1))      # vertical reaction >= 0 only
    elif option == "decol":
        m.set_support(n[8], decol=("z", +1))         # the whole support is released if it lifts off
    case_ = m.analyze().case(1)
    R = dict(case_.reactions())
    Rb = R.get(n[8], (0.0,) * 6)[2]
    print(f"{str(option):6}: reactions A = {R[n[0]][2] / 1e3:7.3f}, B = {R[n[4]][2] / 1e3:7.3f}, "
          f"C = {round(Rb / 1e3, 3) + 0.0:7.3f} kN; uz(C) = {case_.displacement(n[8])[2] * 1e3:7.3f} mm")
print(f"expected free uplift: theta_B L = q L^3 / (24 EI) x L = {q * Ls**4 / (24 * EI) * 1e3:.3f} mm")

# Elastic support defined by its matrix (6 diagonal terms), rotated by 90° about Z:
# the "x" spring of the support acts along global Y
m = keta.Model()
st = m.add_material(e=210e9, nu=0.3, rho=0.0)
a, b = m.add_node(0, 0, 0), m.add_node(2, 0, 0)
m.add_truss(a, b, m.add_section_props(0.01, 1e-4, 1e-4, 1e-4), st)
m.fix(a)
m.add_support(b, dz=True, rx=True, ry=True, rz=True)
m.set_support(b, stiffness=[5e6, 0, 0, 0, 0, 0], rot=math.pi / 2)
m.add_point_load(b, fx=2e3, fy=1e3)
d = m.analyze().case(1).displacement(b)
print(f"rotated support: uy = {d[1] * 1e3:.4f} mm (1 kN / 5 MN/m = 0.2000 mm), ux = {d[0] * 1e6:.4f} µm (elongation of the bar)")
Output
None  : reactions A =  21.875, B =  31.250, C =  -3.125 kN; uz(C) =   0.000 mm
uplift: reactions A =  25.000, B =  25.000, C =   0.000 kN; uz(C) =  12.401 mm
decol : reactions A =  25.000, B =  25.000, C =   0.000 kN; uz(C) =  12.401 mm

Under the load on the first span, the bilateral end support holds the beam down (negative reaction of −3.125 kN). Made unilateral, it lifts off: the two spans then behave as a statically determinate beam with a cantilever and the end rises by θB·L.

6.4 Skew supports#

Syntax
m.add_skew_support(node, axes, dx=False, dy=False, dz=False, rx=False, ry=False, rz=False)  →  int
ParameterUnitDefaultMeaning
node——supported node
axes——3 × 3 matrix given by rows: unit vectors of the local x, y, z axes of the support, expressed in the global axes (orthonormal basis)
dx … rz—Falserestrained components, in the support axes

The skew support restrains components expressed in an arbitrary coordinate system: roller on an inclined plane, support of a skew bridge. Its reactions are read by skew_reactions(), which returns for each skew support the triplet (node, reaction in the support axes, reaction in the global axes).

Exampleexamples/manual/ex_appui_biais.py
# Skew support: roller inclined at 30° in the XZ plane at the end of a beam.
import math
import keta

m = keta.Model()
a, c = m.add_node(0, 0, 0), m.add_node(6, 0, 0)
m.add_beam(a, c, m.add_section("IPE400"), m.steel())
m.add_support(a, dx=True, dy=True, dz=True, rx=True)
t = math.radians(30)
axes = [[math.cos(t), 0.0, math.sin(t)],        # local x: free direction of the roller
        [0.0, 1.0, 0.0],                          # local y
        [-math.sin(t), 0.0, math.cos(t)]]         # local z: normal to the rolling plane
m.add_skew_support(c, axes, dy=True, dz=True)     # restrains local y and z
m.add_point_load(c, fz=-50e3)

case_ = m.analyze().case(1)
node, loc, glob = case_.skew_reactions()[0]
print(f"node {node}: local reaction  Rz' = {loc[2] / 1e3:.3f} kN")
print(f"        global reaction Rx = {glob[0] / 1e3:.3f} kN, Rz = {glob[2] / 1e3:.3f} kN")
print(f"reaction of the fixed support: Rx = {case_.reactions()[0][1][0] / 1e3:.3f} kN")
assert abs(loc[2] - 50e3 / math.cos(t)) < 1e-6 * 50e3

6.5 Bars#

Syntax
m.add_beam(n1, n2, section, material, beta=0.0, ecc=None)  →  int
m.add_truss(n1, n2, section, material)  →  int
ParameterUnitDefaultMeaning
n1, n2——origin and end nodes; the local x axis runs from n1 to n2
section——identifier of the section (Section 6.9)
material——identifier of the material (Chapter 7)
betarad0rotation of the local y and z axes about x (Section 6.6)
eccmNoneoffset (ex, ey, ez) of the bar axis with respect to the line of the nodes, global axes (Section 6.7)

add_beam creates a two-node spatial Timoshenko beam with twelve degrees of freedom: tension-compression, Saint-Venant torsion, bending in two planes with shear deformation (taken into account through the shear areas of the section). A section without shear areas gives an Euler-Bernoulli beam. add_truss creates a pin-ended bar that works only in tension-compression.

A bar is straight and of constant section. A curved beam or a beam with variable second moment of area is modelled by a succession of bars.

6.5.1 Bars with variable section#

Syntax
m.set_tapered(bar, law, orig, ext, mid=None)
ParameterUnitDefaultMeaning
bar——bar concerned
law——law of variation: 'lin_y' or 'lin_z' (rectangle whose dimension along y, or along z, varies linearly: linear area and shear areas, cubic or linear second moments of area depending on the axis); 'para' (the inverse of each property varies along the parabola through the three sections)
orig, ext——section at the origin and at the end: section identifier or dict(A, Avy, Avz, Iy, Iz, J)
mid—Nonesection at mid-length, mandatory for 'para'

The stiffness matrix and the equivalent loads of the bar are exact for the given variation of section: they are obtained by integrating the flexibility along the bar. The internal forces at the output stations are obtained by equilibrium. A shear area absent from the dictionary (Avy or Avz) makes the bar infinitely stiff for the corresponding shear force. The other properties (A, Iy, Iz, J) are mandatory and strictly positive, otherwise a ValueError is raised.

Important

set_tapered is called once the nodes, orientation, offsets and material of the bar are final. The bar must carry no hinge. Its mass and geometric stiffness remain those of its own section (that of add_beam): the mode shapes and the buckling of a variable bar are computed with this mean section.

Exampleexamples/manual/ex_sections_variables.py
# Bar with variable section: cantilever of 8 m with linearly varying depth (1.0 -> 0.5 m),
# then inverse parabolic second moment of area; comparison with the integral of M m / EI(x).
import keta

E, L, P, b = 30e9, 8.0, 100e3, 0.3

def cantilever(law, orig, ext, mid=None, n=1):
    m = keta.Model()
    c = m.add_material(e=E, nu=0.2, rho=0.0)
    s = m.add_section_props(sx=0.3, iy=0.025, iz=0.002, ix=0.005)    # "mean" section of the bar
    nd = [m.add_node(L * i / n, 0, 0) for i in range(n + 1)]
    bars = [m.add_beam(nd[i], nd[i + 1], s, c) for i in range(n)]
    m.fix(nd[0])
    m.set_tapered(bars[0], law, orig, ext, mid)
    m.add_point_load(nd[-1], fz=-P)
    return m.analyze().case(1).displacement(nd[-1])[2]

def rect(h):                                    # properties of a b x h rectangle (no shear)
    return dict(A=b * h, Iy=b * h**3 / 12, Iz=h * b**3 / 12, J=0.1 * b**3 * h)

def simpson(f, a, c, n=2000):
    step = (c - a) / n
    return step / 3 * sum((1 if i in (0, n) else 4 if i % 2 else 2) * f(a + i * step) for i in range(n + 1))

w = cantilever("lin_z", rect(1.0), rect(0.5))
h = lambda x: 1.0 + (0.5 - 1.0) * x / L
wref = simpson(lambda x: P * (L - x) ** 2 / (E * b * h(x) ** 3 / 12), 0, L)
print(f"linear depth: uz = {w * 1e3:.5f} mm; integral of M m / EI = {-wref * 1e3:.5f} mm")

I0, Im, I1 = 0.025, 0.012, 0.004
w = cantilever("para", dict(A=0.3, Iy=I0, Iz=0.002, J=0.005), dict(A=0.2, Iy=I1, Iz=0.002, J=0.005),
               dict(A=0.25, Iy=Im, Iz=0.002, J=0.005))
inv = lambda t: (1 / I0) * 2 * (t - 0.5) * (t - 1) - (1 / Im) * 4 * t * (t - 1) + (1 / I1) * 2 * t * (t - 0.5)
wref = simpson(lambda x: P * (L - x) ** 2 * inv(x / L) / E, 0, L)
print(f"inverse parabolic: uz = {w * 1e3:.5f} mm; integral = {-wref * 1e3:.5f} mm")

# the same cantilever split into 8 prismatic bars of mean depth
m = keta.Model()
c = m.add_material(e=E, nu=0.2, rho=0.0)
nd = [m.add_node(i * 1.0, 0, 0) for i in range(9)]
for i in range(8):
    hm = h(i + 0.5)
    m.add_beam(nd[i], nd[i + 1], m.add_section_props(sx=b * hm, iy=b * hm**3 / 12, iz=hm * b**3 / 12, ix=0.01), c)
m.fix(nd[0])
m.add_point_load(nd[-1], fz=-P)
print(f"8 prismatic bars: uz = {m.analyze().case(1).displacement(nd[-1])[2] * 1e3:.5f} mm")
Output
linear depth: uz = -37.21745 mm; integral of M m / EI = -37.21745 mm
inverse parabolic: uz = -31.57333 mm; integral = -31.57333 mm
8 prismatic bars: uz = -37.46347 mm

A single variable bar gives the value of the Mohr integral; the subdivision into eight prismatic bars of mean depth gives a deflection approximate to within 0.7 %.

6.6 Orientation of sections#

The default orientation of the local axes is described in Section 3.3. The parameter beta of add_beam rotates the y and z axes by an angle β about the x axis, in the positive sense. It serves to place the strong axis of a rolled section in the desired plane or to orient the section of a column.

Exampleexamples/manual/ex_orientation.py
# Section orientation (angle beta): the same IPE 300 cantilever bent
# about its strong axis (beta = 0), then about its weak axis (beta = pi/2).
import math
import keta

def z(x):                     # removes the displayed negative zero
    return 0.0 if abs(x) < 1e-6 else x

for beta in (0.0, math.pi / 2):
    m = keta.Model()
    a, b = m.add_node(0, 0, 0), m.add_node(3, 0, 0)
    m.add_beam(a, b, m.add_section("IPE300"), m.steel(), beta=beta)
    m.fix(a)
    m.add_point_load(b, fz=-5e3)
    case_ = m.analyze().case(1)
    uz = case_.displacement(b)[2]
    x, N, Vy, Vz, T, My, Mz = case_.bar_forces(1)[0]
    print(f"beta = {beta:.4f} rad: uz = {uz * 1e3:8.3f} mm, My(0) = {z(My) / 1e3:7.3f} kN.m, Mz(0) = {z(Mz) / 1e3:7.3f} kN.m")

# Local axes of a vertical bar and of an inclined bar (read through the deflection under a load)
m = keta.Model()
a, b = m.add_node(0, 0, 0), m.add_node(0, 0, 4)
m.add_beam(a, b, m.add_section_rect(0.3, 0.5), m.concrete())
m.fix(a)
m.add_point_load(b, fx=10e3)          # horizontal force at the column head
x, N, Vy, Vz, T, My, Mz = m.analyze().case(1).bar_forces(1)[0]
print(f"column, base: Vy = {z(Vy) / 1e3:.3f} kN, Vz = {Vz / 1e3:.3f} kN, My = {My / 1e3:.3f} kN.m, Mz = {z(Mz) / 1e3:.3f} kN.m")
Output
beta = 0.0000 rad: uz =   -2.654 mm, My(0) =  15.000 kN.m, Mz(0) =   0.000 kN.m
beta = 1.5708 rad: uz =  -35.554 mm, My(0) =   0.000 kN.m, Mz(0) = -15.000 kN.m
column, base: Vy = 0.000 kN, Vz = -10.000 kN, My = 40.000 kN.m, Mz = 0.000 kN.m

For β = π/2, the IPE 300 cantilever is bent about its weak axis: the deflection is multiplied by the ratio of the second moments of area (apart from shear deformations) and the moment appears on the Mz component. For the vertical column, the local z axis points along −X: a force along +X produces a negative shear force Vz and a positive moment My at the base.

6.7 Offsets#

The parameter ecc = (ex, ey, ez) shifts the axis of the bar with respect to the line joining its nodes, by the same vector at both ends, expressed in the global axes. The nodes are connected to the bar axis by infinitely rigid arms. This arrangement serves to model a beam under a slab, a composite deck or an offset crosshead.

Exampleexamples/manual/ex_excentrement.py
# Offsets: schematic composite deck, beam offset by 0.6 m below the node line.
import keta

def z(x):                     # removes the displayed negative zero
    return 0.0 if abs(x) < 1e-6 else x

L = 10.0
for e in (0.0, -0.6):
    m = keta.Model()
    a, b = m.add_node(0, 0, 0), m.add_node(L, 0, 0)
    beam = m.add_beam(a, b, m.add_section("HEB500"), m.steel(), ecc=(0.0, 0.0, e))
    m.add_support(a, dx=True, dy=True, dz=True, rx=True)
    m.add_support(b, dy=True, dz=True)
    m.add_point_load(b, fx=-200e3)                  # horizontal thrust on the movable support
    case_ = m.analyze().case(1)
    st = case_.bar_forces(beam)
    print(f"e = {e:5.2f} m: N = {st[5][1] / 1e3:8.2f} kN, My(mid) = {z(st[5][5]) / 1e3:8.2f} kN.m, "
          f"ux(B) = {case_.displacement(b)[0] * 1e3:7.4f} mm, ry(B) = {z(case_.displacement(b)[4]) * 1e3:7.4f} mrad")
Output
e =  0.00 m: N =  -200.00 kN, My(mid) =     0.00 kN.m, ux(B) = -0.3991 mm, ry(B) =  0.0000 mrad
e = -0.60 m: N =  -200.00 kN, My(mid) =  -120.00 kN.m, ux(B) = -3.5981 mm, ry(B) = -2.6658 mrad

When the beam is offset 0.6 m below the line of the nodes, the horizontal thrust applied on this line creates a constant moment N·e = 120 kN·m in the beam and a rotation of the supports.

Note

The internal forces at the output stations are those of the bar, referred to its own axis; the reactions and displacements are those of the nodes.

6.7.1 Offsets specific to each end#

Syntax
m.set_eccentricity(bar, origin=(0, 0, 0), end=(0, 0, 0))
m.add_beam(n1, n2, section, material, ecc=None, ecc_end=None)  →  int
ParameterUnitDefaultMeaning

origin, endm(0, 0, 0)shift of the origin and of the end of the bar with respect to their nodes, global axes

The area and second moments of area are computed by integration over the contour (Green's theorem). The torsion constant, the warping constant, the shear centre and the shear areas come from the solution, by six-node triangular finite elements, of the Saint-Venant warping problem, Δω=0 in the section with ∂ω/∂n=zny​−ynz​ on the contour. The returned dictionary contains A, yc, zc (centroid), Iy, Iz, Iyz, the principal second moments of area I1, I2 and their angle phi, J, Iw, the shear centre ys, zs, the areas Avy, Avz and the distances to the extreme fibres ymax, zmax.

A composite section is described by its materials and by the regions they occupy. Its properties are those of the section transformed to the modulus of material 0, E_ref: A remains the geometric area, EA_ref is the transformed area ∑(Ei​/Eref​)Ai​, and the centroid, the second moments of area, the torsion and the shear areas are weighted in the same way. The Poisson's ratios are then those of the materials.

section_stress computes the stresses in the section under given actions. At each requested point it returns sigma, tau_y, tau_z, tau and von_mises. It also gives sigma_min and sigma_max, each in the form (value, y, z), which are the extremes of the normal stress due to N, My and Mz, reached on the contour, and von_mises_max, taken at the nodes of the mesh. The normal stress is N/A+My​z/Iy​−Mz​y/Iz​ about the centroid, multiplied by Ei​/Eref​ in material i of a composite section; the warping stress due to the bimoment B is added to it. The shear stresses due to Vy, Vz and T come from the Saint-Venant fields computed by finite elements. A point outside the section is rejected.

import_dxf reads the contour of a section in a drawing: closed polylines, with their arcs, and circles. The largest closed contour is the outer contour, the others its voids; all are returned in counterclockwise order, ready for section_polygon and add_section_polygon.

Important

In a model, the axes of the polygon must be its principal axes of inertia (Iyz​=0): an arbitrary contour is first rotated or re-centred by the user.

With quadrilaterals, the mid-line of a wall joins the midpoints of its two short sides p-s and q-r, and the thickness at an end is its short side projected on the normal to the mid-line: for a corner cut on the skew, this gives the actual thickness and not the length of the diagonal. The ratio of the two thicknesses is free: a cantilever slab that goes from 0.50 m to 0.20 m is described by a single wall. The transverse component of these forces is subtracted from the shear force, Vz,web​=Vz​−∑Nf​dzf​/dx (EN 1992-1-1, 6.2.1(1)). The result gives the shear force left to the web (Vy, Vz), the part carried by the chords (relief_y, relief_z) and the factors of the section, that is, the part carried per unit of (N, My, Mz). For two equal chords at a distance h apart, the lower one inclined at α, under a moment M alone, the web keeps V−(M/h)tanα. The values are raw: their sign shows whether the chords relieve the web or load it.

6.10 Bars on elastic foundation#

Syntax
m.set_soil(bar, kfx=0.0, kfy=0.0, kfz=0.0, kmx=0.0)
ParameterUnitDefaultMeaning

The bar rests on a bed of continuous springs (Winkler model), expressed in its local axes. In linear statics, a frame bar without release or shear area is computed from the exact solution of the beam on elastic foundation (transfer functions in series): the displacements and internal forces do not depend on the mesh, and the internal forces at the output stations include the soil reaction. A Timoshenko bar or a bar with a release, and the other analyses (modes, buckling, nonlinear), use a consistent stiffness matrix, whose results converge with the mesh. The soil pressure is k·w, w being the local displacement (complete example in Chapter 23).

# compared with Hetényi's infinite beam: the solution is exact whatever the mesh.

    sec = m.add_section_props(sx=0.8, iy=1.0 * 0.8**3 / 12, iz=0.8 * 1.0**3 / 12, ix=0.1)  # rigid in shear

    case_ = m.analyze().case(1)

    M0 = case_.bar_forces(bars[n // 2])[0][5]
    assert abs(case_.sum_reactions()[2]) < 1e-3     # the whole load goes into the soil

6.11 Links between nodes#

6.11.1 Rigid link#

Syntax

Each slave follows the rigid-body motion of the master on the chosen components (master-slave elimination). Rigid links serve to represent diaphragms, rigid floors, rigid cross-beams or the connection between a deck and a support.

Important

Not all analyses handle links between nodes. Linear statics, mode shapes, staged construction, influence lines, harmonic response, link laws and the large-displacement analysis (nonlinear) accept them. The second-order analysis does not admit any. Buckling does not admit an elastic link between distinct nodes. Arc length admits neither elastic links nor a load applied to a slave. The large-displacement time-history analysis does not admit rigid links. The spectral analysis of a model with links requires the number of modes to be fixed (parameter n_modes, Chapter 14). An analysis that does not handle a type of link raises an explicit ValueError.

6.13.1 Isolated catenary, tension adjustment and Ernst stiffness#

Syntax
keta.catenary(dx, dz, l0, ea, w)  →  dict
keta.catenary_l0(dx, dz, ea=, w=, h=None, end_tension=None, end=2)  →  float
keta.ernst_stiffness(ea=, l0=, dx=, dz=, w=, h=)  →  dict
keta.ernst_modulus(e, gamma, l, sigma)  →  float
cable_static.ernst_substitute()  →  (Model, axial, chi)

catenary solves the elastic catenary of an isolated cable between two fixed anchorages with projections dx (horizontal, positive) and dz (vertical). It returns the horizontal tension H, the vertical components V1 and V2 = V1 + w·l0 and the tensions T1 and T2. catenary_l0 performs the inverse calculation: it gives the unstretched length that produces a horizontal tension h, or a tension end_tension at the end end (1 or 2), on the taut branch. A tension below the minimum of the hanging cable (there is then no taut root) or beyond 4.5 % strain is rejected.

ernst_stiffness gives the equivalent linear chord stiffness 1/k = l0/EA + (w·dx)² Lc/(12 T³), where T = h Lc/dx is the tension at mid-chord (classical Ernst form). It also gives the sag parameter χ = w Lc cos²α/h, with a note beyond 0.1; the deviation from the elastic catenary is about χ²/5. ernst_modulus gives the equivalent modulus E/(1 + (γl)²E/(12σ³)). ernst_substitute replaces each cable of a cable_static state by a truss with its Ernst stiffness, for the linear analyses. It also returns the tensions of the state (prestress to be passed to a modal or second-order analysis, which contributes the chord stiffness T/Lc) and χ for each cable. The trusses follow the geometry of the model: if the state has displaced the anchorages, the exact linearisation is the tangent of the state (cable_static(...).tangent()).

Creates a flat three-node shell facet: membrane with in-plane rotational degrees of freedom (Allman element) and locking-free Mindlin-Reissner bending (MITC3 element). Shells are assembled with bars and take part in statics, natural modes, buckling, second order and large displacements. Non-uniform torsion (warping, lateral_buckling), the modes of rotating structures and the second-order phases of a staged construction reject a model with shells (ValueError). Slabs and walls are meshed with Python loops, each quadrilateral cell being split into two triangles.

Exampleexamples/manual/ex_coques.py
# Shells: square slab of 6 m, simply supported on its four edges, under 10 kN/m2.
import keta

a, t, q, E, nu = 6.0, 0.20, 10e3, 30e9, 0.2
D = E * t**3 / (12 * (1 - nu**2))
print(f"Navier solution (0.00406 q a^4 / D): {-0.00406 * q * a**4 / D * 1e3:.4f} mm")

def slab(n):                                       # n x n cells, 2 triangles per cell
    m = keta.Model()
    concrete = m.add_material(e=E, nu=nu)
    g = [[m.add_node(a * i / n, a * j / n, 0.0) for i in range(n + 1)] for j in range(n + 1)]
    for j in range(n):
        for i in range(n):
            n1, n2, n3, n4 = g[j][i], g[j][i + 1], g[j + 1][i + 1], g[j + 1][i]
            m.add_shell(n1, n2, n3, t, concrete, slab=1)
            m.add_shell(n1, n3, n4, t, concrete, slab=1)
    for j in range(n + 1):
        for i in range(n + 1):
            if i in (0, n) or j in (0, n):
                m.add_support(g[j][i], dz=True)                 # simple support along the boundary
    m.add_support(g[0][0], dx=True, dy=True, rz=True)           # restraint of the rigid-body motions
    m.add_support(g[0][n], dy=True)
    m.add_surface_pressure(1, qz=-q)                            # vertical pressure (global axes)

    case_ = m.analyze().case(1)
    return case_.displacement(g[n // 2][n // 2])[2], case_.sum_reactions()[2]

for n in (6, 12, 24):
    w, R = slab(n)
    print(f"{n:3d} x {n:<3d} cells: centre deflection = {w * 1e3:.4f} mm, total reaction = {R / 1e3:.3f} kN")

6.15 Continuum elements#

Syntax
m.add_continuum(kind, nodes, material, t=1.0)  →  int
ParameterUnitDefaultMeaning
kind——'plane_stress' (plane stress), 'plane_strain' (plane strain), 'axisymmetric' (axisymmetric, r = x, axis y, per radian) or 'solid' (solid)
nodes——nodes of the element: 3, 4, 6 or 8 nodes in plane (T3, Q4, T6, Q8), 4, 8 or 20 in solid (T4, H8, H20)
material——material
tm1thickness of the plane elements

Plane elements are described in the XY plane. The nodes are given vertices first, in counterclockwise order (bottom face then top face for hexahedra), then the mid-side nodes side by side (Q8: sides 0-1, 1-2, 2-3, 3-0). Unused degrees of freedom are restrained automatically. The stress at a point of natural coordinates ξ is read by continuum_stress(element, xi): (σx, σy, τxy, σz) in plane, (σr, σz, σθ, τrz) in axisymmetry, (σx, σy, σz, τxy, τyz, τzx) in solid.

Exampleexamples/manual/ex_continu.py
# Continuum elements: beam modelled as a plane-stress wall (Q8 quadrilaterals),
# clamped, with a distributed shear force of 20 kN at its free end.
import keta

L, h, t, P, E = 4.0, 0.4, 0.1, 20e3, 30e9
nx, ny = 20, 2
m = keta.Model()
mat = m.add_material(e=E, nu=0.0)
# nodes at half-element spacing (the element centres are not used)
N = {}
for j in range(2 * ny + 1):
    for i in range(2 * nx + 1):
        if i % 2 == 0 or j % 2 == 0:
            N[i, j] = m.add_node(L * i / (2 * nx), h * j / (2 * ny), 0.0)
elements = []
for j in range(0, 2 * ny, 2):
    for i in range(0, 2 * nx, 2):
        corners = [N[i, j], N[i + 2, j], N[i + 2, j + 2], N[i, j + 2]]            # anticlockwise
        midsides = [N[i + 1, j], N[i + 2, j + 1], N[i + 1, j + 2], N[i, j + 1]]   # sides 01, 12, 23, 30
        elements.append(m.add_continuum("plane_stress", corners + midsides, mat, t=t))
for j in range(2 * ny + 1):
    m.add_support(N[0, j], dx=True, dy=True)                   # clamping of the end face x = 0
for e in elements[nx - 1::nx]:                                 # last element of each row
    m.add_continuum_traction(e, face=1, traction=(0.0, -P / (h * t), 0.0))   # side x = L

case_ = m.analyze().case(1)
v = case_.displacement(N[2 * nx, ny])[1]
I = t * h**3 / 12
print(f"tip deflection (mid-depth fibre): {v * 1e3:.4f} mm")
print(f"Timoshenko beam (shear 5/6): {-(P * L**3 / (3 * E * I) + P * L / (5 / 6 * E / 2 * t * h)) * 1e3:.4f} mm")
sx, sy, txy, sz = case_.continuum_stress(elements[nx // 2], (0.0, -1.0, 0.0))  # midspan, bottom edge
print(f"sigma_x at x = {L / 2 + L / (2 * nx):.1f} m, bottom fibre: {sx / 1e6:.3f} MPa "
      f"(simple bending: {-P * (L / 2 - L / (2 * nx)) * h / 2 / I / 1e6:.3f} MPa)")
