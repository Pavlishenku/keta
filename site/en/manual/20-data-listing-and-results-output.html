Chapter 20 Data listing and results output

20.1 Data listing#

The data of a model can be read back in three ways:

  • print(m) summarises the model (numbers of nodes, bars, cases, combinations); m.node_count and m.bar_count give the counts;
  • json.loads(m.to_json()) gives a complete dictionary: lists nodes (identifier and coordinates), materials, sections (with the computed properties props: A, Iy, Iz, J, Avy, Avz), bars, supports, cases (loads of each case), combinations, etc.; any data item can be read there to print or check it;
  • m.export_script() produces a readable Python script that rebuilds the model (Section 5.5).

Each object has a concise text representation (print(r)): number of cases, first critical factor, first frequency, etc. The methods return ordinary Python numbers, tuples, lists and dictionaries, independent of the model: they remain valid if the model is modified afterwards.

20.3 Storing and reading back results#

Syntax
r.save(path, note="")
m.read_results(path)  →  Results
keta.results_info(path)  →  dict(schema_version, generator, note, sign_convention, cases, combinations)
ParameterUnitDefaultMeaning
path——JSON file of the results store
note—""free provenance note: name of the study, date, command

Results.save writes all the cases and combinations of a static computation (displacements, reactions, end forces and forces at the output stations with their deflections, soil pressures, shells, links, general links, skew supports) into a JSON document that carries a schema number, its provenance (the program and its version, the note) and the sign convention of the forces. The numbers are written with 17 significant digits: Model.read_results returns a Results object identical to the bit, read by the same methods. The file is read back on the model that produced it; a document of a more recent schema, of another origin, or computed on other nodes or bars is rejected.

Exampleexamples/manual/ex_magasin_resultats.py
# Simple portal frame analysed, saved, then read back: the forces read back are bit-for-bit identical.
import os
import tempfile
import keta

m = keta.Model()
a, b, c = m.add_node(0, 0, 0), m.add_node(0, 0, 4), m.add_node(6, 0, 4)
steel = m.add_material(210e9, 0.3, rho=7850.0)
section = m.add_section_rect(0.2, 0.4)
column, beam = m.add_beam(a, b, section, steel), m.add_beam(b, c, section, steel)
m.add_support(a, True, True, True, True, True, True)
m.add_support(c, False, True, True)
m.add_udl(beam, wz=-20e3, case=1)
m.add_point_load(b, fx=15e3, case=2)

r = m.analyze(stations=5)
path = os.path.join(tempfile.mkdtemp(), "frame.json")
r.save(path, note="portal frame, variant A")
info = keta.results_info(path)
print(f"schema {info['schema_version']}, note “{info['note']}”, {info['cases']} cases")

reread = m.read_results(path)
identical = all(reread.case(i).bar_forces(bar) == r.case(i).bar_forces(bar)
                for i in (1, 2) for bar in (column, beam))
print("forces read back identical:", identical)
print(f"moment at the column head, case 1: {reread.case(1).bar_forces(column)[-1][5] / 1e3:.2f} kN.m")
Output
schema 1, note “portal frame, variant A”, 2 cases
forces read back identical: True
moment at the column head, case 1: 29.87 kN.m

20.4 Output#

Results are output by the means of Python:

  • formatted printing by f"…" strings, with the desired number of decimals and unit (f"{M / 1e3:8.2f} kN.m");
  • tables written in CSV format by the csv module, read back by a spreadsheet;
  • curves and diagrams plotted by a graphics library (for example matplotlib, to be installed separately), from the lists of values (abscissae x/L, forces);
  • archiving in JSON format by the json module, or by Results.save for reading back without loss of precision.
Note

Very small residual values (of the order of 10⁻¹² times the useful values) come from floating-point arithmetic. For a clean output, round (round(x, 3) + 0.0 also removes the display of a negative zero).

The example of Chapter 21 writes a CSV table; those of Chapters 10 and 23 output tables of forces.
