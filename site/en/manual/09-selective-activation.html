Chapter 9 Selective activation

Selective activation consists in making only part of the defined bars and supports take part in the analysis: modelling variants, temporary structure, study of part of a structure. There are two ways of doing this in Python.

9.1 Parametric construction of the model#

As a keta model is built by a script, the most direct way of computing several variants is to write a function that builds the model from parameters, and to add only the elements wanted. The example of the hinges (Section 6.8) and that of the unilateral supports (Section 6.3) follow this approach: a function two_span(hinge) or make_beam() creates each variant, which is analysed independently.

def model(with_prop):
    m = keta.Model()
    ...                                   # common nodes, bars and supports
    if with_prop:
        m.add_support(n_mid, dz=True)  # temporary support
    return m

for variant in (True, False):
    r = model(variant).analyze()
Note

Unused objects need not be created: a node that carries no element is restrained automatically and has no influence on the analysis.

9.2 Activation and deactivation during staged construction#

The staged construction analysis (Chapter 13) activates and deactivates bars, supports and links during the stages. The bars not cited by an activate key are active from the start. A stage can:

  • activate bars (activate), which are born stress-free in the current geometry;
  • deactivate bars (deactivate): the forces they carried are returned to the remaining structure;
  • add or remove supports (add_supports, remove_supports): the removal of a support returns its reaction to the structure.

Without a time-dependent law, the dates have no effect: an elastic staged construction analysis therefore gives, with a single model, states in which part of the structure is inactive. Section 13.5 gives an example (beam cast on a prop that is added, then removed).

9.3 Global activation outside staged construction#

Syntax
m.set_active(bars=None, supports=None)
ParameterUnitDefaultMeaning
bars—Noneactive bars; None: all
supports—Nonenodes whose supports are active; None: all

The subsequent analyses (static, modes, buckling, spectra…) see only the active bars and supports. Loads and added masses carried by inactive bars are ignored; a node that is no longer connected to any element is held fixed. m.set_active() restores the complete structure. The staged construction analysis also starts from the active structure: the deactivated bars and supports are absent from it, and its own activation keys apply to what remains.

Exampleexamples/manual/ex_activation.py
# Global activation: the same structure analysed with and without its intermediate support.
import keta

L, q = 6.0, 10e3
m = keta.Model()
n = [m.add_node(L * i, 0, 0) for i in range(3)]
s = m.add_section("IPE450")
b = [m.add_beam(n[i], n[i + 1], s, m.steel()) for i in range(2)]
m.add_support(n[0], dx=True, dy=True, dz=True, rx=True, rz=True)
m.add_support(n[1], dz=True)
m.add_support(n[2], dy=True, dz=True, rz=True)
for x in b:
    m.add_udl(x, wz=-q)
r = dict(m.analyze().case(1).reactions())
print(f"continuous beam: central support {r[n[1]][2] / 1e3:.2f} kN (5qL/4 = {1.25 * q * L / 1e3:.2f})")
m.set_active(supports=[n[0], n[2]])
r = dict(m.analyze().case(1).reactions())
print(f"central support deactivated: end support {r[n[0]][2] / 1e3:.2f} kN (qL = {q * L / 1e3:.2f})")
m.set_active()                                             # back to the full structure
print("reactivated:", round(dict(m.analyze().case(1).reactions())[n[1]][2] / 1e3, 2), "kN")
Output
continuous beam: central support 74.74 kN (5qL/4 = 75.00)
central support deactivated: end support 60.00 kN (qL = 60.00)
reactivated: 74.74 kN

The reaction of the central support (74.74 kN) is slightly lower than 5qL/4: the shear deformation of the steel section relieves the intermediate support.
