Chapitre 20 Rappel des données et édition des résultats

20.1 Rappel des données#

Les données d'un modèle se relisent de trois façons :

  • print(m) résume le modèle (nombres de nœuds, de barres, de cas, de combinaisons) ; m.node_count et m.bar_count en donnent les effectifs ;
  • json.loads(m.to_json()) donne un dictionnaire complet : listes nodes (identifiant et coordonnées), materials, sections (avec les caractéristiques calculées props : A, Iy, Iz, J, Avy, Avz), bars, supports, cases (charges de chaque cas), combinations, etc. ; on y lit toute donnée pour l'imprimer ou la contrôler ;
  • m.export_script() produit un script Python lisible qui reconstruit le modèle (paragraphe 5.5).

Chaque objet a une représentation textuelle concise (print(r)) : nombre de cas, premier facteur critique, première fréquence, etc. Les méthodes renvoient des nombres, des tuples, des listes et des dictionnaires Python ordinaires, indépendants du modèle : ils restent valables si le modèle est modifié ensuite.

20.3 Conservation et relecture des résultats#

Syntaxe
r.save(path, note="")
m.read_results(path)  →  Results
keta.results_info(path)  →  dict(schema_version, generator, note, sign_convention, cases, combinations)
ParamètreUnitéDéfautSignification
path——fichier JSON du magasin de résultats
note—""note libre de provenance : nom de l'étude, date, commande

Results.save écrit tous les cas et combinaisons d'un calcul statique (déplacements, réactions, efforts d'extrémité et efforts aux sections d'étude avec leurs flèches, pressions de sol, coques, liaisons, liaisons générales, appuis biais) dans un document JSON qui porte un numéro de schéma, sa provenance (le programme et sa version, la note) et la convention de signe des efforts. Les nombres sont écrits avec 17 chiffres significatifs : Model.read_results rend un objet Results identique au bit près, lu par les mêmes méthodes. Le fichier se relit sur le modèle qui l'a produit ; un document d'un schéma plus récent, d'une autre origine, ou calculé sur d'autres nœuds ou barres est refusé.

Exempleexamples/manuel/ex_magasin_resultats.py
# Portique simple calculé, enregistré, puis relu : les efforts relus sont identiques au bit près.
import os
import tempfile
import keta

m = keta.Model()
a, b, c = m.add_node(0, 0, 0), m.add_node(0, 0, 4), m.add_node(6, 0, 4)
acier = m.add_material(210e9, 0.3, rho=7850.0)
section = m.add_section_rect(0.2, 0.4)
poteau, traverse = m.add_beam(a, b, section, acier), m.add_beam(b, c, section, acier)
m.add_support(a, True, True, True, True, True, True)
m.add_support(c, False, True, True)
m.add_udl(traverse, wz=-20e3, case=1)
m.add_point_load(b, fx=15e3, case=2)

r = m.analyze(stations=5)
chemin = os.path.join(tempfile.mkdtemp(), "portique.json")
r.save(chemin, note="portique, variante A")
info = keta.results_info(chemin)
print(f"schéma {info['schema_version']}, note « {info['note']} », {info['cases']} cas")

relu = m.read_results(chemin)
identique = all(relu.case(i).bar_forces(barre) == r.case(i).bar_forces(barre)
                for i in (1, 2) for barre in (poteau, traverse))
print("efforts relus identiques :", identique)
print(f"moment en tête de poteau, cas 1 : {relu.case(1).bar_forces(poteau)[-1][5] / 1e3:.2f} kN.m")
Sortie obtenue
schéma 1, note « portique, variante A », 2 cas
efforts relus identiques : True
moment en tête de poteau, cas 1 : 29.87 kN.m

20.4 Édition#

L'édition des résultats se fait par les moyens de Python :

  • impression formatée par les chaînes f"…", avec le nombre de décimales et l'unité voulus (f"{M / 1e3:8.2f} kN.m") ;
  • tableaux écrits au format CSV par le module csv, relus par un tableur ;
  • courbes et diagrammes tracés par une bibliothèque graphique (par exemple matplotlib, à installer séparément), à partir des listes de valeurs (abscisses x/L, efforts) ;
  • archivage au format JSON par le module json, ou par Results.save pour une relecture sans perte de précision.
Remarque

Les très petites valeurs résiduelles (de l'ordre de 10⁻¹² fois les valeurs utiles) proviennent de l'arithmétique en virgule flottante. Pour une édition propre, on arrondit (round(x, 3) + 0.0 supprime aussi l'affichage d'un zéro négatif).

L'exemple du chapitre 21 écrit un tableau CSV ; ceux des chapitres 10 et 23 éditent des tableaux d'efforts.
