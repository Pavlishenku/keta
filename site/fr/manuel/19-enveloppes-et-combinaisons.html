Chapitre 19 Enveloppes et combinaisons

19.1 Combinaisons linéaires#

Syntaxe
m.add_combination(terms, name=None)  →  int
ParamètreUnitéDéfautSignification
terms——liste de couples (coefficient, numéro de cas)
name—Nonenom de la combinaison

Une combinaison est la somme pondérée des résultats de plusieurs cas de charge. Elle est calculée par m.analyze() en même temps que les cas, et ses résultats se lisent par r.combo(numéro) avec les mêmes méthodes qu'un cas ; r.combo_ids donne la liste des combinaisons. Les combinaisons ont leur propre numérotation (1, 2, …), indépendante de celle des cas.

Remarque

La combinaison des résultats suppose la linéarité. Pour les calculs non linéaires (appuis unilatéraux, lois de liaison, second ordre, grands déplacements), on crée un cas de charge qui contient les charges pondérées de la combinaison et on le calcule directement.

19.2 Enveloppes#

Une enveloppe est l'ensemble des valeurs extrêmes d'une grandeur sur plusieurs cas, combinaisons ou dispositions de charges. Les résultats étant des nombres Python, une enveloppe se construit directement par min et max sur les listes de valeurs, avec la logique de présence voulue (charge permanente toujours présente avec son coefficient favorable ou défavorable, charges variables présentes ou absentes). Les valeurs concomitantes s'obtiennent en conservant, avec l'extrême, l'indice de la combinaison qui le produit.

Pour les charges mobiles, les extrêmes sont donnés directement par les fonctions de placement du chapitre 12, qui renvoient aussi la position correspondante.

19.3 Combinaisons réglementaires de l'EN 1990#

Syntaxe
keta.combine_extreme(effects, actions, state='uls', maximise=True, rules={})  →  dict
ParamètreUnitéDéfautSignification
effects——effet de chaque action pour un coefficient unité (une valeur par action)
actions——description des actions : dict(case, name, kind, gamma_sup, gamma_inf, psi0, psi1, psi2, exclusive, may_lead)
state—'uls'état limite : 'uls' (ELU fondamental), 'characteristic', 'frequent', 'quasi_permanent'
maximise—Truerecherche du maximum (False : minimum)
rules—{}règles de l'annexe nationale : dict(gamma_G_sup, gamma_G_inf, gamma_set_sup, gamma_set_inf, xi, eq610ab)

Chaque action est permanente (kind='permanent'), tassement ('settlement') ou variable ('variable', défaut). Pour une action variable, gamma_sup vaut 1,5 et gamma_inf 0 par défaut ; ψ0, ψ1, ψ2 valent 0,7, 0,5 et 0,3. Des actions portant la même étiquette exclusive ne peuvent agir ensemble ; may_lead=False interdit à une action d'être dominante. La fonction recherche la combinaison la plus défavorable parmi toutes celles que ces règles autorisent : chaque action permanente avec son coefficient favorable ou défavorable, chaque action variable dominante ou d'accompagnement, présente ou absente. Elle renvoie dict(value, label, terms), terms étant la liste des couples (cas, coefficient) de la combinaison trouvée. Avec eq610ab=True, l'ELU utilise les expressions 6.10a et 6.10b au lieu de 6.10.

Exempleexamples/manuel/ex_combinaisons.py
# Combinaisons et enveloppes : poutre continue 2 x 10 m, charges permanentes et
# charges d'exploitation travée par travée ; combinaisons, enveloppe et extrême EN 1990.
import keta

m = keta.Model()
nd = [m.add_node(1.0 * i, 0, 0) for i in range(21)]
sec = m.add_section_props(sx=0.4, iy=0.02, iz=0.01, ix=0.01)
b = [m.add_beam(nd[i], nd[i + 1], sec, m.concrete() if i == 0 else 1) for i in range(20)]
m.add_support(nd[0], dx=True, dy=True, dz=True, rx=True)
m.add_support(nd[10], dy=True, dz=True)
m.add_support(nd[20], dy=True, dz=True)
for bi in b:
    m.add_udl(bi, wz=-20e3, case=1)                       # G : 20 kN/m
for bi in b[:10]:
    m.add_udl(bi, wz=-15e3, case=2)                       # Q1 : travée 1
for bi in b[10:]:
    m.add_udl(bi, wz=-15e3, case=3)                       # Q2 : travée 2
for c, nom in [(1, "G"), (2, "Q travée 1"), (3, "Q travée 2")]:
    m.name_case(c, nom)
c1 = m.add_combination([(1.35, 1), (1.5, 2), (1.5, 3)], name="ELU deux travées")
c2 = m.add_combination([(1.35, 1), (1.5, 2)], name="ELU travée 1")
r = m.analyze(stations=11)
print(r)
for c in r.combo_ids:
    res = r.combo(c)
    print(f"{res} : M sur appui = {res.bar_forces(b[9])[-1][5] / 1e3:8.2f} kN.m, "
          f"M en x = 4 m = {res.bar_forces(b[3])[-1][5] / 1e3:8.2f} kN.m")

# Enveloppe programmée : G toujours présent (1,35 ou 1,0), chaque Q présent (1,5) ou absent
def efforts(cas, barre):
    return [s[5] for s in r.case(cas).bar_forces(barre)]
env = {}
for bi in b:
    G, Q1, Q2 = efforts(1, bi), efforts(2, bi), efforts(3, bi)
    vals = [[gG * g + a * q1 + c * q2 for g, q1, q2 in zip(G, Q1, Q2)]
            for gG in (1.0, 1.35) for a in (0.0, 1.5) for c in (0.0, 1.5)]
    env[bi] = [(min(v), max(v)) for v in zip(*vals)]
mmin = min(lo for bi in b for lo, _ in env[bi])
mmax = max(hi for bi in b for _, hi in env[bi])
print(f"enveloppe de My : min {mmin / 1e3:.2f} kN.m (travées), max {mmax / 1e3:.2f} kN.m (appui)")

# Extrême exact d'une réponse selon l'EN 1990 (effets des actions unitaires fournis)
e = [r.case(c).bar_forces(b[9])[-1][5] for c in (1, 2, 3)]
x = keta.combine_extreme(e, [dict(case=1, kind="permanent"),
                             dict(case=2, name="Q1", psi0=0.7),
                             dict(case=3, name="Q2", psi0=0.7)], state="uls", maximise=True)
print(f"EN 1990, ELU, max du moment sur appui : {x['value'] / 1e3:.2f} kN.m ; {x['label']} ; termes {[(c, round(f, 4)) for c, f in x['terms']]}")
x = keta.combine_extreme(e, [dict(case=1, kind="permanent"), dict(case=2, name="Q1"), dict(case=3, name="Q2")],
                         state="characteristic", maximise=True)
print(f"EN 1990, ELS caractéristique : {x['value'] / 1e3:.2f} kN.m ; termes {[(c, round(f, 4)) for c, f in x['terms']]}")

L'enveloppe programmée reprend les deux combinaisons explicites. La combinaison de l'EN 1990 avec ψ0 = 0,7 donne pour le moment sur appui une valeur inférieure à la combinaison « toutes charges à 1,5 » : la seconde travée n'y intervient qu'en accompagnement (1,5 × 0,7 = 1,05).

19.4 Génération des combinaisons et enveloppes#

Syntaxe
m.generate_combinations(permanent, variable=[], state='uls', use_610ab=False, xi=0.85)  →  [ids]
r.envelope(cases=None, combos=None)  →  (minimum, maximum)
r.envelope_factored([(case, c_min, c_max), …])  →  (minimum, maximum)
r.concomitant(what, bar=0, station=0, comp=0, node=0, cases=None, combos=None)  →  dict
ParamètreUnitéDéfautSignification
permanent——cas permanents, ou dict(case, gamma_sup=1,35, gamma_inf=1,0) — un même couple pour tous
variable—[]dict(case, name, psi0, psi1, psi2, gamma_q), ou (cas, 'traffic'|'wind'|'thermal'|'snow') pour les valeurs de l'annexe nationale française
state—'uls''uls', 'characteristic', 'frequent', 'quasi_permanent'
what——'bar_force' (barre, numéro de section d'étude, composante 0 à 5 : N Vy Vz T My Mz), 'reaction' ou 'displacement' (nœud, composante)

generate_combinations ajoute au modèle les combinaisons de l'état demandé, chaque action variable étant tour à tour dominante, et renvoie leurs numéros. À l'ELU (6.10) :

j∑​γG,j​Gj​+γQ,1​Q1​+i>1∑​γQ,i​ψ0,i​Qi​(19.1)

les actions permanentes étant prises toutes à γG,sup​, puis toutes à γG,inf​. Les enveloppes portent sur toutes les composantes : les deux bornes renvoyées s'utilisent comme un résultat ordinaire (bar_forces, reactions…). envelope_factored prend chaque cas seul, avec le coefficient de son intervalle qui lui est le plus défavorable : ce n'est pas une combinaison. concomitant cherche les extrêmes d'une composante et renvoie, avec eux, l'état complet du cas ou de la combinaison qui les produit, par exemple un moment avec son effort normal concomitant.

Exempleexamples/manuel/ex_combinaisons_en1990.py
# Combinaisons de l'EN 1990 générées dans le modèle, enveloppes et valeurs concomitantes.
import keta

L = 10.0
m = keta.Model()
a, b = m.add_node(0, 0, 0), m.add_node(L, 0, 0)
p = m.add_beam(a, b, m.add_section("HEB300"), m.steel())
m.add_support(a, dx=True, dy=True, dz=True, rx=True, rz=True)
m.add_support(b, dy=True, dz=True, rz=True)
m.add_udl(p, wz=-10e3, case=1); m.name_case(1, "G")
m.add_udl(p, wz=-5e3, case=2); m.name_case(2, "trafic")
m.add_udl(p, wz=2e3, case=3); m.name_case(3, "vent")
elu = m.generate_combinations([1], [(2, "traffic"), (3, "wind")], state="uls")
qp = m.generate_combinations([1], [(2, "traffic"), (3, "wind")], state="quasi_permanent")
r = m.analyze()
for i in elu + qp:
    print(f"combinaison {i} : réaction en A = {dict(r.combo(i).reactions())[a][2] / 1e3:8.2f} kN")
bas, haut = r.envelope(combos=elu)
print(f"enveloppe ELU de My à mi-portée : [{bas.bar_forces(p)[5][5] / 1e3:.2f} ; {haut.bar_forces(p)[5][5] / 1e3:.2f}] kN.m")
cc = r.concomitant("reaction", node=a, comp=2, combos=elu)
print(f"réaction maximale {cc['max'] / 1e3:.2f} kN ({cc['source_max']}), "
      f"My concomitant = {cc['state_max'].bar_forces(p)[5][5] / 1e3:.2f} kN.m")
