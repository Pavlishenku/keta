Chapitre 35 Treillis de Sierpiński

35.1 Énoncé#

Un treillis plan de barres articulées a la forme d'un triangle équilatéral de côté L = 24 m, subdivisé selon la construction de Sierpiński : au niveau 1, le triangle est divisé en quatre par les milieux de ses côtés et le triangle central est retiré ; au niveau n, la même opération est appliquée à chacun des trois triangles du niveau n − 1. Toutes les barres sont en acier (E = 210 GPa, ρ = 7850 kg/m³) et ont une aire A = 40 cm². Le sommet inférieur gauche est une articulation fixe, le sommet inférieur droit un appui glissant. Deux cas sont étudiés, pour les niveaux 1 à 5 : une charge verticale P = 100 kN au sommet supérieur, puis le poids propre. On cherche la flèche du sommet sous P, les barres qui travaillent et les réactions sous le poids propre.

35.2 Script#

Exempleexamples/manuel/app_sierpinski.py
# Treillis articulé de Sierpiński : charge au sommet et poids propre, niveaux 1 à 5.
import math
import keta

L, A, P = 24.0, 4e-3, 100e3                 # côté [m], aire des barres [m2], charge au sommet [N]

def aretes(n, a=(0.0, 0.0), b=(1.0, 0.0), c=(0.5, math.sqrt(3) / 2)):
    """Côtés des plus petits triangles du triangle de Sierpiński de niveau n (côté 1)."""
    if n == 0:
        return [(a, b), (b, c), (c, a)]
    mi = lambda p, q: ((p[0] + q[0]) / 2, (p[1] + q[1]) / 2)
    ab, bc, ca = mi(a, b), mi(b, c), mi(c, a)
    return aretes(n - 1, a, ab, ca) + aretes(n - 1, ab, b, bc) + aretes(n - 1, ca, bc, c)

def treillis(n):
    m = keta.Model()
    acier = m.steel()
    sec = m.add_section_props(sx=A, iy=1e-8, iz=1e-8, ix=1e-8)
    nd = {}
    def noeud(p):
        cle = (round(p[0] * 2**(n + 1)), round(p[1] / (math.sqrt(3) / 2) * 2**n))   # indices de grille
        if cle not in nd:
            nd[cle] = m.add_node(p[0] * L, 0, p[1] * L)
        return nd[cle]
    barres = [m.add_truss(noeud(p), noeud(q), sec, acier) for p, q in aretes(n)]
    for k in nd.values():
        m.add_support(k, dy=True)                                 # treillis plan XZ
    gauche, droite, sommet = nd[(0, 0)], nd[(2**(n + 1), 0)], nd[(2**n, 2**n)]
    m.add_support(gauche, dx=True, dz=True)
    m.add_support(droite, dz=True)
    m.add_point_load(sommet, fz=-P, case=1)
    m.add_self_weight(case=2)
    return m, nd, barres, gauche, droite, sommet

EA = 210e9 * A
fleche = 3 * P * L / (4 * EA)               # travaux virtuels : (2/3 + 1/12) P L / EA
print(f"flèche au sommet sous P, forme fermée 3PL/4EA = {fleche * 1e3:.4f} mm")
print("niveau  noeuds  barres  actives sous P   w [mm]   poids [kN]   réactions [kN]")
for n in range(1, 6):
    m, nd, barres, gauche, droite, sommet = treillis(n)
    assert len(barres) + 3 == 2 * len(nd)                        # isostatique : b + 3 = 2 noeuds
    r = m.analyze()
    w = -r.case(1).displacement(sommet)[2]
    actives = sum(abs(r.case(1).bar_forces(b)[0][1]) > 1e-9 * P for b in barres)
    longueur = 3 * L * 1.5**n                                     # 3^(n+1) barres de longueur L / 2^n
    poids = 7850 * 9.80665 * A * longueur
    reac = dict(r.case(2).reactions())
    rg, rd = reac[gauche][2], reac[droite][2]
    print(f"{n:6d} {len(nd):7d} {len(barres):7d} {actives:15d} {w * 1e3:8.4f} {poids / 1e3:12.3f}"
          f"   {rg / 1e3:6.3f} + {rd / 1e3:6.3f}")
    assert actives == 3 * 2**n                                    # seules les barres du contour travaillent
    assert abs(w - fleche) < 1e-9 * fleche
    assert abs(rg - poids / 2) < 1e-9 * poids and abs(rd - poids / 2) < 1e-9 * poids

35.3 Résultats#

Au niveau n, le treillis compte b=3n+1 barres et (3n+1+3)/2 nœuds : b+3=2nnœuds​, il est isostatique à tous les niveaux et ses efforts se déduisent de l'équilibre seul. Sous la charge au sommet, l'état où seules les barres du contour travaillent l'équilibre : chacun des deux côtés inclinés porte l'effort −P/3​ (compression), la base l'effort P/(23​) (traction), et chaque nœud intérieur à un côté reçoit deux efforts égaux et opposés de barres alignées, les barres intérieures restant à effort nul. Le treillis étant isostatique, cet état est le seul : 3·2n barres travaillent, ce que keta retrouve. Le théorème des travaux virtuels donne la flèche du sommet

δ=i∑​EANi​Nˉi​ℓi​​=(2⋅31​+121​)EAPL​=4EA3PL​(35.1)

où Nˉi​ sont les efforts sous une charge unité au sommet : 2,1429 mm, indépendante du niveau de subdivision. keta donne cette valeur à tous les niveaux, à 10⁻⁹ près.

La longueur totale des barres, 3n+1L/2n=3L(3/2)n, croît sans borne avec le niveau alors que l'aire du triangle reste la même : c'est le propre d'une figure fractale, ici de dimension ln3/ln2≈1,585. Le poids propre ρgA3L(3/2)n se répartit, par symétrie, en deux réactions égales ; le calcul le confirme.
