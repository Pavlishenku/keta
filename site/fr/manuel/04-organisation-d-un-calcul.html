Chapitre 4 Organisation d'un calcul

4.1 Déroulement d'un script#

Un calcul keta est un script Python qui enchaîne quatre étapes :

  1. importation du module : import keta ;
  2. description du modèle : création d'un objet keta.Model(), puis appel de ses méthodes add_… pour définir nœuds, matériaux, sections, éléments, appuis, liaisons et chargements ;
  3. lancement d'un ou plusieurs calculs : m.analyze() pour la statique linéaire, m.modal(), m.buckling(), m.phased(), etc. Chaque calcul renvoie un objet de résultats indépendant ; le modèle n'est pas modifié ;
  4. exploitation des résultats : lecture des déplacements, réactions et efforts par les méthodes des objets de résultats, impression, calculs complémentaires en Python.

Les étapes peuvent être répétées : un modèle peut être complété après un premier calcul puis recalculé, plusieurs modèles peuvent coexister dans un même script et un modèle peut être construit par une fonction Python paramétrée (chapitre 21).

4.2 Identifiants#

Toutes les méthodes add_… qui créent un objet renvoient son identifiant, un entier. Les identifiants sont attribués automatiquement, dans l'ordre de création, séparément pour chaque famille d'objets : le premier nœud porte le numéro 1, la première barre le numéro 1, le premier matériau le numéro 1, etc. On conserve ces identifiants dans des variables ou des listes Python pour les réutiliser :

a = m.add_node(0, 0, 0)                 # a == 1
b = m.add_node(6, 0, 0)                 # b == 2
acier = m.steel()                       # matériau 1
poutre = m.add_beam(a, b, m.add_section("IPE300"), acier)    # barre 1

Les familles numérotées séparément sont : nœuds, barres (poutres et treillis), câbles, matériaux, sections, liaisons, coques, éléments continus, câbles de précontrainte, combinaisons. Il n'est pas possible de choisir soi-même un numéro ; la correspondance avec une numérotation extérieure se fait par un dictionnaire Python.

Important

Les identifiants sont des entiers sans signification géométrique. Un identifiant d'une famille ne doit pas être utilisé pour une autre (un numéro de nœud à la place d'un numéro de barre) : selon les cas, l'erreur est signalée (KeyError) ou porte sur un autre objet existant.

4.3 Cas de charge#

Les charges sont regroupées en cas de charge repérés par un numéro entier choisi par l'utilisateur et passé par le paramètre case des méthodes de chargement (valeur par défaut 1). Un cas est créé à la première charge qui le cite ; il peut être nommé par m.name_case. Les cas sont calculés ensemble, en une seule factorisation de la matrice de rigidité. Les combinaisons linéaires de cas sont définies par m.add_combination (chapitre 19).

Remarque

m.harmonic et m.psd (chapitre 14) désignent le cas par son numéro avec l'argument case_id ; leur argument case en donne le rang (0 pour le premier cas dans l'ordre croissant des numéros).

4.4 Résultats#

Chaque calcul renvoie un objet propre à l'analyse. La statique linéaire renvoie un objet Results, qui donne accès aux résultats de chaque cas (r.case(i)) et de chaque combinaison (r.combo(j)) sous la forme d'objets CaseResult. Les principales méthodes de lecture sont communes à la plupart des analyses statiques :

MéthodeRésultat
displacement(nœud)tuple (dx, dy, dz, rx, ry, rz), repère global
reactions()liste de (nœud, (Fx, Fy, Fz, Mx, My, Mz)) des nœuds appuyés
sum_reactions()résultante (Fx, Fy, Fz) des réactions
bar_forces(barre)liste de (x/L, N, Vy, Vz, T, My, Mz) aux sections d'étude
end_forces(barre)les 12 efforts d'extrémité, repère local
max_displacement()plus grande translation nodale (norme)

Le chapitre 20 décrit l'ensemble des objets de résultats et l'annexe B le format de chacun.

4.5 Exemple commenté#

L'exemple ci-dessous illustre l'organisation d'un script complet : une poutre continue à deux travées sur un appui central élastique, dont la réaction est comparée à la forme fermée.

Exempleexamples/manuel/ex_appuis.py
# Appuis rigides et élastiques : poutre continue de 2 x 8 m, appui central élastique.
import keta

L, q, ks = 8.0, -30e3, 20e6          # portée [m], charge [N/m], raideur [N/m]
m = keta.Model()
n = [m.add_node(L * i, 0.0, 0.0) for i in range(3)]
sec = m.add_section_props(sx=0.05, iy=2.0e-3, iz=1.0e-3, ix=1.0e-3)   # rigide à l'effort tranchant
mat = m.add_material(e=30e9, nu=0.2)
b = [m.add_beam(n[i], n[i + 1], sec, mat) for i in range(2)]

m.add_support(n[0], dx=True, dy=True, dz=True, rx=True)   # appui fixe (rotations ry, rz libres)
m.add_support(n[1], dy=True, kz=ks)                       # appui élastique vertical
m.add_support(n[2], dy=True, dz=True)                     # appui glissant
for bi in b:
    m.add_udl(bi, wz=q)

cas = m.analyze().case(1)
for nd, (fx, fy, fz, mx, my, mz) in cas.reactions():
    print(f"noeud {nd} : Fz = {fz / 1e3:9.3f} kN")
w1 = cas.displacement(n[1])[2]
print(f"tassement de l'appui élastique : {w1 * 1e3:.3f} mm")

# Contrôle (forme fermée) : R1 = (5 q (2L)^4 / 384 EI) / (1/ks + (2L)^3 / 48 EI)
EI, Lt = 30e9 * 2.0e-3, 2 * L
R1 = (5 * -q * Lt**4 / (384 * EI)) / (1 / ks + Lt**3 / (48 * EI))
print(f"réaction attendue : {R1 / 1e3:.3f} kN")
assert abs(dict(cas.reactions())[n[1]][2] - R1) < 1e-8 * R1
assert abs(w1 + R1 / ks) < 1e-12
Sortie obtenue
noeud 1 : Fz =    95.094 kN
noeud 2 : Fz =   289.811 kN
noeud 3 : Fz =    95.094 kN
tassement de l'appui élastique : -14.491 mm
réaction attendue : 289.811 kN

Le script crée trois nœuds (n est la liste de leurs identifiants), une section définie par ses caractéristiques et un matériau, puis deux barres. L'appui de gauche bloque les trois translations et la torsion ; l'appui central bloque la translation transversale dy et porte un ressort vertical kz ; l'appui de droite est glissant selon X. Une charge répartie verticale est appliquée aux deux barres dans le cas 1, le cas par défaut. Après le calcul, la boucle sur cas.reactions() imprime les réactions verticales ; la réaction de l'appui élastique est ensuite contrôlée par la forme fermée.
