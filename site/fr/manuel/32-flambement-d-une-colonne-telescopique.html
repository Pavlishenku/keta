Chapitre 32 Flambement d'une colonne télescopique

32.1 Énoncé#

Une colonne télescopique en acier (E = 206 GPa), encastrée en pied et libre en tête, se compose de n tronçons de section décroissante, n variant de 1 à 8. Une force verticale P comprime la colonne en tête. Les longueurs et les inerties principales I₁ et I₂ des tronçons sont données dans le script ; la colonne déployée atteint 122,4 m. On cherche la charge critique pour chaque nombre de tronçons.

32.2 Modèle#

Chaque tronçon est découpé en quatre barres. Aucun plan de flambement n'est imposé : keta recherche le premier mode parmi les deux plans principaux. La charge de référence de 1 kN fait du facteur critique la charge critique en kN.

32.3 Script#

Exempleexamples/manuel/app_flambement_gradins.py
# Flambement d'une colonne télescopique encastrée en pied, libre en tête, de 1 à 8 tronçons de
# section décroissante, comprimée par une force verticale en tête.
import math
import keta

E = 206e9
TRONCONS = [  # (longueur [m], aire [m2], inertie 1 [m4], inertie 2 [m4]), du pied vers la tête
    (15.3, 0.0906, 0.04326, 0.03466), (15.5, 0.0645, 0.02609, 0.02281),
    (15.4, 0.0529, 0.01906, 0.01703), (15.6, 0.0478, 0.01441, 0.01335),
    (15.4, 0.0415, 0.01039, 0.01043), (15.3, 0.0346, 0.00749, 0.00756),
    (15.1, 0.0296, 0.00541, 0.00560), (14.8, 0.0302, 0.00463, 0.00489)]

def keta_pcr(n, decoupage=4):
    m = keta.Model()
    acier = m.add_material(e=E, nu=0.3)
    pied = m.add_node(0, 0, 0)
    m.fix(pied)
    z, prec = 0.0, pied
    for L, A, I1, I2 in TRONCONS[:n]:
        sec = m.add_section_props(sx=A, iy=I1, iz=I2, ix=I1 + I2)
        for _ in range(decoupage):                  # 4 barres par tronçon
            z += L / decoupage
            nn = m.add_node(0, 0, z)
            m.add_beam(prec, nn, sec, acier)
            prec = nn
    m.add_point_load(prec, fz=-1e3)                 # 1 kN : le facteur critique est Pcr en kN
    return m.buckling(n_modes=1).factors[0]

def residu(P, n, plan):
    # u = déport de la tête - flèche : u'' + (P / EI) u = 0 dans chaque tronçon,
    # u = 1 et u' = 0 au pied (encastrement), u = 0 en tête (point d'application de P)
    u, du = 1.0, 0.0
    for t in TRONCONS[:n]:
        L, k = t[0], math.sqrt(P / (E * t[2 + plan]))
        c, s = math.cos(k * L), math.sin(k * L)
        u, du = u * c + du / k * s, -u * k * s + du * c
    return u

def pcr_exacte(n):
    valeurs = []
    for plan in (0, 1):                             # chacun des deux plans principaux
        P = 1e3
        while residu(P * 1.01, n, plan) > 0:        # première racine : premier changement de signe
            P *= 1.01
        a, b = P, P * 1.01                          # puis dichotomie
        for _ in range(60):
            c = (a + b) / 2
            if residu(c, n, plan) > 0:
                a = c
            else:
                b = c
        valeurs.append(a)
    return min(valeurs) / 1e3

L1, I2 = TRONCONS[0][0], TRONCONS[0][3]                # inertie la plus faible du tronçon 1
print(f"1 tronçon, Euler pi2 E I / 4 L2 = {math.pi**2 * E * I2 / (4 * L1**2) / 1e3:.1f} kN")
print(" n   hauteur     Pcr keta      Pcr exacte     écart")
for n in range(1, 9):
    pk, pe = keta_pcr(n), pcr_exacte(n)
    ecart = 100 * (pk - pe) / pe
    H = sum(t[0] for t in TRONCONS[:n])
    print(f"{n:2d}   {H:6.1f} m  {pk:10.1f} kN  {pe:10.1f} kN  {round(ecart, 4) + 0:7.4f} %")
    assert abs(ecart) < 0.01

32.4 Résultats#

Soit δ le déplacement de la tête et w(z) la flèche. Le moment fléchissant vaut P(δ−w), et la variable u=δ−w vérifie dans le tronçon i

u′′+ki2​u=0,ki​=P/EIi​​(32.1)

De tronçon en tronçon, u et u′ sont continus : u(z)=u0​coski​(z−z0​)+(u0′​/ki​)sinki​(z−z0​), z₀ étant la base du tronçon. L'encastrement impose u=δ (normé à 1) et u′=0 en pied, et la tête u=0. La charge critique est la plus petite racine de uteˆte​(P)=0, que le script isole par balayage puis dichotomie, pour chacun des deux plans. Pour un seul tronçon, l'équation se réduit à coskL=0, soit la charge d'Euler π2EI/4L2.

L'inertie I₂ gouverne toutes les configurations. L'écart de keta, de 3·10⁻⁵ pour la colonne d'un tronçon, provient de la rigidité géométrique cubique des barres ; il décroît quand le nombre total de barres augmente. Avec une seule barre par tronçon, buckling_cte_var(0, 1, bisection=True) (chapitre 16) emploie les fonctions de stabilité et donne les mêmes charges critiques à 10⁻⁸ près.
