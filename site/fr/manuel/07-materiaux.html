Chapitre 7 Matériaux

Un matériau est défini par ses constantes élastiques, sa masse volumique et son coefficient de dilatation thermique. Il peut recevoir en outre une loi de comportement différé (fluage et retrait) utilisée par le phasage de construction (chapitre 13).

7.1 Matériaux prédéfinis#

Syntaxe
m.steel()  →  int
m.concrete()  →  int

Créent un matériau usuel et renvoient son identifiant :

MéthodeEνρα
steel()210 GPa0,37850 kg/m³1,2·10⁻⁵ /K
concrete()33 GPa0,22500 kg/m³1,0·10⁻⁵ /K
Remarque

Chaque appel crée un nouveau matériau. Pour affecter le même matériau à plusieurs barres, on conserve son identifiant dans une variable.

7.2 Matériau quelconque#

Syntaxe
m.add_material(e, nu, rho=None, alpha_temp=None, name=None, g=None, damping=None)  →  int

Le comportement est élastique linéaire isotrope. Les lois non linéaires de matériau sont propres aux analyses qui les emploient : fibres (chapitre 17), éléments continus plastiques (chapitre 17), feu (chapitre 18).

L'exemple des actions thermiques du chapitre 11 utilise alpha_temp : l'effort normal d'une barre bi-encastrée chauffée y vaut −E·A·α·ΔT.

7.3 Comportement différé du béton#

7.3.1 Principe#

Sous une contrainte σ appliquée à l'âge t₀, la déformation d'un béton à l'âge t s'écrit :

ε(t) = σ / E(t₀) + φ(t, t₀) · σ / Eréf + εcs(t)

où φ(t, t₀) est le coefficient de fluage, Eréf le module auquel il se rapporte et εcs la déformation de retrait (négative en raccourcissement). Pour une histoire de contrainte variable, keta applique le principe de superposition de Boltzmann à chaque incrément de contrainte, avec son propre âge de chargement. Ces lois interviennent uniquement dans le phasage de construction (m.phased, chapitre 13), entre les dates des phases ; l'analyse statique analyze n'utilise que le module E du matériau.

7.3.3 Loi définie par l'utilisateur#

Syntaxe
m.set_concrete_law_functions(material, phi, E_ref, shrinkage=None)
ParamètreUnitéDéfautSignification
phi——fonction Python phi(t, t0) du coefficient de fluage (âges en jours)
E_refPa—fonction E_ref(t0) : module de référence de φ pour un chargement à l'âge t0
shrinkage—Nonefonction shrinkage(t) de la déformation de retrait (négative en raccourcissement) ; None : pas de retrait

Les fonctions sont appelées par le noyau pendant le calcul de phasage ; elles peuvent représenter une loi d'essai ou une loi réglementaire non disponible.

Important

Le module instantané utilisé pour chaque incrément de chargement est le module E du matériau (add_material), quel que soit l'âge du béton. On choisit donc E cohérent avec la loi (par exemple le module moyen à 28 jours). Les lois différées et les fonctions Python ne sont pas conservées par to_json.

7.3.4 Exemple#

Un poteau de 4 m, de section 0,40 × 0,40 m, est chargé à 28 jours de 2 MN. Son raccourcissement est calculé à plusieurs dates pour différentes lois ; la ligne « EC2, fluage seul » retranche le raccourcissement d'un poteau identique non chargé (retrait seul).

Exempleexamples/manuel/ex_lois_beton.py
# Lois différées du béton : raccourcissement d'un poteau de 4 m sous 2 MN appliqués
# à 28 jours, pour plusieurs lois de fluage et de retrait.
import math
import keta

def poteau(regle=None, fonctions=None, charge=True, **parametres):
    m = keta.Model()
    c = m.add_material(e=35e9, nu=0.2, rho=0.0)
    if regle:
        m.set_concrete_law(c, regle, **parametres)
    if fonctions:
        m.set_concrete_law_functions(c, *fonctions)
    s = m.add_section_rect(0.4, 0.4)
    a, b = m.add_node(0, 0, 0), m.add_node(0, 0, 4)
    m.add_beam(a, b, section=s, material=c)
    m.fix(a)
    m.add_support(b, dx=True, dy=True, rx=True, ry=True, rz=True)
    m.add_point_load(b, fz=-2e6 if charge else 0.0, case=1)
    dates = [28, 128, 365, 3650, 10000]
    r = m.phased([dict(name=f"{t} j", time=t, cases=[1] if t == 28 else []) for t in dates],
                 creep_substeps_per_decade=16)
    return [r.phase(i).displacement(b)[2] for i in range(len(r))]

u0 = -2e6 * 4 / (35e9 * 0.16)
print(f"raccourcissement élastique : {u0 * 1e3:.4f} mm")
print("dates [j]                 :      28      128      365     3650    10000")
cas = [("COURBON", dict(e_direct=35e9)),
       ("EC2", dict(fc=35e6, rh=70.0, h_mm=400.0, cement="N")),
       ("EC2, fluage seul", None),
       ("BPEL", dict(fc=35e6, rh=70.0, rm_cm=10.0)),
       ("FIB2010", dict(fc=35e6, rh=70.0, h_mm=400.0, cement="N"))]
for nom, par in cas:
    if par is None:   # retrait seul (poteau non chargé) retranché de la loi EC2
        u = [a - b for a, b in zip(poteau("EC2", **cas[1][1]),
                                   poteau("EC2", charge=False, **cas[1][1]))]
    else:
        u = poteau(nom, **par)
    print(f"{nom:17} [mm] : " + " ".join(f"{x * 1e3:8.3f}" for x in u))

# Loi définie par l'utilisateur : phi(t, t0) = 1,5 (1 - exp(-(t - t0) / 100)), module constant
phi = lambda t, t0: 1.5 * (1 - math.exp(-(t - t0) / 100)) if t > t0 else 0.0
u = poteau(fonctions=(phi, lambda t0: 35e9))
print(f"{'utilisateur':17} [mm] : " + " ".join(f"{x * 1e3:8.3f}" for x in u))
print(f"contrôle COURBON à 10000 j : u0 (1 + phi) = {u0 * (1 + 2 * (1 - math.exp(-0.006 * 9972))) * 1e3:.3f} mm")

Le retrait n'agit qu'à partir de la première phase (28 jours), date d'entrée de la structure dans le calcul. Avec la loi de Courbon, le raccourcissement final vaut u₀ (1 + φ∞).

7.4 Fonctions des lois différées#

Les lois de comportement différé sont aussi accessibles comme fonctions du temps, pour des calculs de section, des vérifications ou des études de sensibilité.

7.4.1 Loi codée#

Syntaxe
loi = keta.concrete_law(code, **paramètres)  →  ConcreteLaw
loi.E(t), loi.Ev(t), loi.E_ref(t0), loi.fc_mean(t), loi.phi(t, t0), loi.eps_sh(t, ts), loi.n_equiv(),
loi.compliance(t, t0)

Les codes et les paramètres sont ceux de set_concrete_law (tableau 7.1). L'objet donne le module instantané E(t), le module différé Ev(t) des règles BPEL et BHP, le module de référence du fluage, la résistance moyenne à l'âge t, le coefficient de fluage, le retrait à l'âge t pour un séchage débutant à ts (négatif en raccourcissement), le coefficient d'équivalence et la fonction de fluage J(t, t₀) = 1/E(t₀) + φ(t, t₀)/Eréf(t₀). Les âges sont en jours.

7.4.2 Formules de l'EN 1992-1-1#

Syntaxe
keta.ec2_phi(t, t0, fck, rh=70, h0=0.3, cement='N')
keta.ec2_shrinkage(t, fck, rh=70, h0=0.3, cement='N', ts=3, autogenous=True)
keta.ec2_ecm(fck)
keta.aaem_modulus(E, dphi, chi=0.8)
keta.nonlinear_creep_factor(sigma_c, fcm_t0)

Coefficient de fluage (annexe B), retrait total de dessiccation et endogène (§ 3.1.4), module sécant moyen, module effectif ajusté à l'âge E / (1 + χ Δφ) et coefficient de fluage non linéaire exp(1,5 (kσ − 0,45)). h0 est le rayon moyen 2 Ac/u en mètres.

7.4.3 Relaxation et pertes#

Syntaxe
keta.ec2_relaxation_ratio(t_hours, sigma_pi, fpk, cls=2, rho1000=2.5, seuil=None, capped=False)
keta.bpel_relaxation(t_days, sigma, fprg, rho1000)
keta.ip2_relaxation(t_hours, sigma_pi, rg, rho1000, rho3000)
keta.ec2_deferred_loss(eps_cs, Ep, d_sigma_pr, Ecm, phi, sigma_c, Ap, Ac, Ic, zcp)
keta.ip2_lump_sum(sigma_b, sigma_pi, fprg, Ep, rh, final_relaxation, n=6.0, eps_r=None)  →  dict
keta.bpel_lump_sum(sigma_b, sigma_pi, fprg, Ep, rh, rho1000, n=6.0, eps_r=None, mu0=None)  →  dict
keta.bpel_mu0(rho1000)  →  μ0

Perte relative par relaxation de l'EN 1992-1-1 (éq. 3.28 à 3.30 ; avec capped=True, le temps est plafonné à seuil heures, ou à 500 000 heures pour seuil=0 ; sans seuil, il n'est pas plafonné), perte par relaxation du BPEL [Pa] et de l'Instruction provisoire n° 2, et perte différée de l'équation 5.46 de l'EN 1992-1-1 [Pa].

ip2_lump_sum et bpel_lump_sum donnent les pertes différées forfaitaires de l'Instruction provisoire n° 2 et du BPEL à partir de la contrainte finale du béton au niveau du câble sigma_b (compression positive), de la tension initiale sigma_pi, de la résistance garantie fprg, du module Ep et de l'humidité relative rh en pour cent. Elles rendent elastic (n/2 σ_b, soit 3 σ_b avec le coefficient réglementaire n = 6), shrinkage (ε_r E_p), creep (2 n σ_b pour l'IP2, 2,5 n σ_b pour le BPEL), relaxation, viscoelastic et total = elastic + viscoelastic, en pascals. Pour l'IP2, la relaxation finale est donnée et le total différé vaut retrait + fluage + relaxation × (1 − (retrait + fluage) / (σ_pi − 0,55 f_prg)), sans relaxation quand la chute de tension dépasse cette marge. Pour le BPEL, la relaxation vaut 6/100 ρ1000 (σ_pi / f_prg − μ0) σ_pi, nulle en dessous de μ0, et le total différé retrait + fluage + 5/6 de la relaxation ; μ0 suit ρ1000 (0,43 jusqu'à 2,5 %, 0,35 jusqu'à 8 %, 0,30 au-delà) sauf mu0 imposé. Le retrait forfaitaire ε_r est le plus fort en climat sec : 4·10⁻⁴ sous 65 % d'humidité et 3·10⁻⁴ au-dessus pour l'IP2, 3·10⁻⁴ et 2·10⁻⁴ pour le BPEL ; eps_r l'impose.

7.4.4 Intégrale héréditaire#

Syntaxe
keta.log_time_grid(t0, dt_min, dt_max, n)  →  [t]
keta.volterra_strain(J, t, sigma)  →  [ε]

7.4.5 Coefficients d'affinité#

Chaque terme d'une loi codée peut être multiplié par un coefficient d'affinité, transmis comme les autres paramètres à set_concrete_law ou à keta.concrete_law :

ParamètreUnitéDéfautSignification
k_modulus—1module instantané
k_shrinkage_autogenous, k_shrinkage_drying—1retrait endogène, retrait de dessiccation
k_creep_basic, k_creep_drying—1fluage propre, fluage de dessiccation
k_creep_kinetics—1cinétique du fluage
k_*_kinetics—1cinétiques de chaque terme (lois de l'EN 1992-1-1:2027) : l'âge est divisé par le coefficient dans la fonction du temps du terme

Ces coefficients servent à caler une loi sur des mesures ou sur les prescriptions d'un marché. Un mot clé mal orthographié est refusé.

7.4.6 Module à l'âge du chargement dans le phasage#

Par défaut, chaque incrément d'un phasage utilise le module e du matériau. Le paramètre modulus de phased (chapitre 13) donne à la place le module instantané à l'âge du béton de la barre, à la date de la phase : m.phased(phases, modulus=lambda barre, age: loi.E(age)).

En attente
