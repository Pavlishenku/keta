Chapitre 29 Treillis plan articulé

29.1 Énoncé#

Un treillis plan de quatre barres articulées relie les points A (0 ; 0), B (1 ; 0), C (0,5 ; 0,5) et D (2 ; 1), coordonnées en mètres. Les barres AC et BC ont une aire de 2 cm², les barres CD et BD une aire de 1 cm² ; E = 196,2 GPa. A et B sont des articulations fixes ; une force verticale descendante F = 9,81 kN agit en D. On cherche les efforts normaux et les déplacements de C et de D.

29.2 Script#

Exempleexamples/manuel/app_treillis.py
# Treillis plan isostatique de quatre barres articulées : efforts normaux et déplacements.
import math
import keta

E, F = 1.962e11, 9.81e3                    # module d'Young, force verticale descendante en D
P = {"A": (0.0, 0.0), "B": (1.0, 0.0), "C": (0.5, 0.5), "D": (2.0, 1.0)}
BARRES = {"AC": 2e-4, "BC": 2e-4, "CD": 1e-4, "BD": 1e-4}       # aires [m2]

m = keta.Model()
acier = m.add_material(e=E, nu=0.3)
nd = {k: m.add_node(x, 0, z) for k, (x, z) in P.items()}
barre = {}
for nom, aire in BARRES.items():
    sec = m.add_section_props(sx=aire, iy=1e-12, iz=1e-12, ix=1e-12)
    barre[nom] = m.add_truss(nd[nom[0]], nd[nom[1]], sec, acier)
for k in "AB":
    m.add_support(nd[k], dx=True, dy=True, dz=True)
for k in "CD":
    m.add_support(nd[k], dy=True)                                 # treillis plan XZ
m.add_point_load(nd["D"], fz=-F)
cas = m.analyze().case(1)

# Forme fermée : équilibre des nœuds D puis C ; compatibilité des allongements e = N L / (E A)
r2, r10 = math.sqrt(2), math.sqrt(10)
N = {"AC": r2 * F, "BC": -F / r2, "CD": r10 / 2 * F, "BD": -3 / r2 * F}
def unitaire(nom):
    (x1, z1), (x2, z2) = P[nom[0]], P[nom[1]]
    L = math.hypot(x2 - x1, z2 - z1)
    return (x2 - x1) / L, (z2 - z1) / L, L
def deplacement(b1, e1, b2, e2):                                  # n1 . u = e1 et n2 . u = e2
    (a1, c1, _), (a2, c2, _) = unitaire(b1), unitaire(b2)
    det = a1 * c2 - a2 * c1
    return (e1 * c2 - e2 * c1) / det, (a1 * e2 - a2 * e1) / det
e = {k: N[k] * unitaire(k)[2] / (E * BARRES[k]) for k in BARRES}
uC = deplacement("AC", e["AC"], "BC", e["BC"])
nx, nz, _ = unitaire("CD")
uD = deplacement("BD", e["BD"], "CD", e["CD"] + nx * uC[0] + nz * uC[1])

for k in BARRES:
    v = cas.bar_forces(barre[k])[0][1]
    print(f"N {k} : keta {v / 1e3:9.4f} kN   forme fermée {N[k] / 1e3:9.4f} kN   "
          f"écart {round(100 * (v - N[k]) / N[k], 4) + 0:.4f} %")
    assert abs(v - N[k]) < 1e-9 * abs(N[k])
for k, u in (("C", uC), ("D", uD)):
    ux, _, uz, *_ = cas.displacement(nd[k])
    for nom, v, ref in ((f"u{k}", ux, u[0]), (f"w{k}", uz, u[1])):
        print(f"{nom} : keta {v * 1e3:9.6f} mm   forme fermée {ref * 1e3:9.6f} mm   "
              f"écart {round(100 * (v - ref) / ref, 4) + 0:.4f} %")
        assert abs(v - ref) < 1e-9 * abs(ref)

29.3 Résultats#

Le treillis est isostatique : quatre efforts normaux pour les quatre équations d'équilibre des nœuds C et D. L'équilibre du nœud D donne NCD​=210​​F = 15,511 kN (traction) et NBD​=−2​3​F = −20,810 kN (compression) ; celui du nœud C donne NAC​=2​F = 13,873 kN et NBC​=−F/2​ = −6,937 kN. Chaque barre s'allonge de e=NL/EA. Pour une barre i–j de vecteur unitaire n, la compatibilité s'écrit n⋅(uj​−ui​)=e : les barres AC et BC, d'extrémités fixes, déterminent le déplacement de C ; les barres BD et CD, celui de D connaissant celui de C.

keta donne les mêmes efforts et les mêmes déplacements (uD = 3,479 mm, wD = −5,600 mm), à 10⁻⁹ près. Les barres de treillis (add_truss) ne transmettent que l'effort normal ; les rotations des nœuds qui ne portent que de telles barres sont bloquées automatiquement, et seul le degré de liberté hors plan dy des nœuds libres est à bloquer.
