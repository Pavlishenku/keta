Chapitre 5 Commandes générales

5.1 Importation du module#

Syntaxe
import keta
keta.__version__  →  str

Toutes les classes et fonctions sont accessibles dans l'espace de noms keta. L'attribut __version__ donne la version du module. Si l'extension compilée est introuvable, l'importation échoue avec un message rappelant de construire la cible _keta et de compléter PYTHONPATH (chapitre 2).

5.2 Création d'un modèle#

Syntaxe
m = keta.Model()  →  Model

Crée un modèle vide. Un script peut créer autant de modèles que nécessaire ; ils sont indépendants. Les attributs suivants renseignent sur la taille du modèle :

Syntaxe
m.node_count  →  int
m.bar_count  →  int
repr(m)  →  str

node_count et bar_count donnent le nombre de nœuds et de barres (poutres et treillis, câbles exclus). La représentation repr(m), obtenue aussi par print(m), résume le modèle : nombre de nœuds, de barres, de cas et de combinaisons.

5.3 Contrôle d'un modèle#

Syntaxe
m.validate()  →  list[str]

Contrôle la cohérence du modèle sans le calculer : références à des nœuds, matériaux ou sections inexistants, barres de longueur nulle, valeurs non finies, action thermique sur un matériau sans coefficient de dilatation, etc. Renvoie la liste des problèmes trouvés, vide si le modèle est sain. Le contrôle s'arrête au premier problème rencontré : la liste contient au plus un message.

Remarque

Chaque calcul effectue lui-même ce contrôle et lève une ValueError en cas de problème ; validate() permet de le faire à part, par exemple avant une boucle de calculs. Une structure instable (mécanisme) n'est détectée qu'au calcul, lors de la factorisation.

5.4 Sauvegarde et relecture d'un modèle#

Un modèle peut être enregistré sous forme de texte au format JSON, puis reconstruit à l'identique :

Syntaxe
m.to_json()  →  str
keta.Model.from_json(text)  →  Model
ParamètreUnitéDéfautSignification
text——chaîne JSON produite par to_json

Le texte JSON contient les nœuds, matériaux, sections (avec leurs caractéristiques calculées), barres, câbles, appuis, appuis biais, liaisons rigides et élastiques (avec leurs lois), relations linéaires, dalles, coques, éléments continus, masses ponctuelles, nodales et linéiques, câbles de précontrainte, cas de charge et combinaisons. Il s'écrit dans un fichier par les moyens usuels de Python (open(...).write(m.to_json())). Le modèle relu reprend la numérotation : les identifiants créés ensuite suivent les plus grands identifiants existants.

Le contenu JSON est aussi le moyen de connaître les caractéristiques effectivement retenues par le noyau (aires de cisaillement des sections, par exemple, chapitre 6) : json.loads(m.to_json())["sections"].

Important

Les lois différées des matériaux (set_concrete_law et set_concrete_law_functions, chapitre 7) ne font pas partie de cette sauvegarde : elles doivent être redéfinies après relecture. Les barres à section variable (set_tapered) et les barres composites ne peuvent pas être enregistrées : to_json refuse un modèle qui en comporte, plutôt que de l'écrire sans elles.

5.5 Exportation sous forme de script#

Syntaxe
m.export_script(results=None, stations=11)  →  str
ParamètreUnitéDéfautSignification
results—Noneobjet Results d'un calcul statique : le script produit vérifie alors qu'il retrouve les mêmes valeurs
stations—11nombre de sections d'étude par barre du calcul de contrôle

Renvoie un script Python autonome qui reconstruit le modèle et le recalcule. Ce script sert à archiver un calcul sous une forme lisible, à transmettre un modèle ou à constituer un test de non-régression lorsque l'argument results est fourni.

Exempleexamples/manuel/ex_modele_json.py
# Commandes générales : description, validation, sauvegarde et relecture d'un modèle.
import json
import keta

m = keta.Model()
n = [m.add_node(5.0 * i, 0.0, 0.0) for i in range(3)]
s = m.add_section_rect(0.30, 0.60)
c = m.concrete()
b = [m.add_beam(n[i], n[i + 1], s, c) for i in range(2)]
for nd in n:
    m.add_support(nd, dy=True, dz=True, rx=True)
m.add_support(n[0], dx=True)
m.add_udl(b[0], wz=-20e3, case=1)
m.name_case(1, "travée 1 chargée")

print(m)                                   # résumé du modèle
print("noeuds :", m.node_count, " barres :", m.bar_count)
print("problèmes détectés :", m.validate())

texte = m.to_json()                        # modèle complet en JSON
d = json.loads(texte)
print("rubriques JSON :", sorted(k for k in d if d[k]))
m2 = keta.Model.from_json(texte)           # relecture
r1 = m.analyze().case(1).displacement(n[1])[4]
r2 = m2.analyze().case(1).displacement(n[1])[4]
print(f"rotation sur appui : {r1:.6e} rad (original), {r2:.6e} rad (relu)")
assert r1 == r2

script = m.export_script()                 # le modèle sous forme de script Python
print("script exporté :", len(script.splitlines()), "lignes ; début :")
print("\n".join(script.splitlines()[:3]))
print("version du module :", keta.__version__)

5.7 Aide en ligne#

Chaque méthode et chaque fonction porte une description (en anglais) accessible par la fonction help de Python, qui donne la signature, les valeurs par défaut et les mots clés admis :

help(keta.Model.add_beam)
help(keta.Model.phased)
print(keta.convoy_extreme.__doc__)
