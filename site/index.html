keta

Structural analysis: bars, cables, shells and continuum elements

keta is a finite-element kernel for bar structures and bridges, written in C++20 and driven from Python: a script describes the structure, runs the analyses and processes the results.

keta est un noyau de calcul par éléments finis pour les structures à barres et les ouvrages d'art, écrit en C++20 et piloté depuis Python : un script décrit l'ouvrage, lance les calculs et exploite les résultats.
